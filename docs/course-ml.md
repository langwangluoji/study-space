## 怎样阅读

正文先解释问题、符号和推导，接着给出结论与条件。带三角标记的附加框默认关闭，提供数字手算、练习、参考代码和互动图；需要时再打开。数字算例帮助核验，不替代一般结论。

搜索支持 `Ctrl+K`（Mac 为 `⌘+K`），同时检索正文与附加内容。按知识点标记已读或掌握，记录保存在当前浏览器；三讲的标记集中在各讲末“学习记录”中，旧版学习记录会继续读取。
