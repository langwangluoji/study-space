# 光学复习关键总结

[四章完整推导](course-optics.html) · [公式速查与易错辨析](optics-formulas.html) · [37道原作业逐题索引](optics-exercises.html) · [电动力学关联](optics-electrodynamics.html)

## 复习主线

1. 由波形传播到波动方程，再由 Maxwell 方程解释横波、能流及干涉交叉项。
2. 由黑体模式计数和量子平均能量重建 Planck 谱，再导出总辐射与峰值规律。
3. 从跃迁平衡到反转，从往返强度与相位到阈值和纵模，区分传统激光与 FEL。
4. 从电子受迫振动到复极化率、折射率、吸收和色散，再在短波极限中理解光程与光线。

## 应能说明的条件

峰值与有效值的二次量差别；能量谱密度与光子数谱密度的区别；布居寿命与相干寿命；振幅与强度衰减系数；真空波长与介质波长；几何扩散、吸收和倏逝；相速度、群速度与信息前沿。

遇到卡点，沿[公式速查](optics-formulas.html)回到对应的详细章节与自测。
