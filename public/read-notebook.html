import matplotlib.pyplot as plt
from torch.utils.data import DataLoader
from torchvision import transforms
from torchvision.datasets import CIFAR10

classes = (
    "airplane", "automobile", "bird", "cat", "deer",
    "dog", "frog", "horse", "ship", "truck",
)
raw_train = CIFAR10(root="data", train=True, download=True, transform=None)
raw_test = CIFAR10(root="data", train=False, download=True, transform=None)
image, label = raw_train[0]
print("sizes:", len(raw_train), len(raw_test))
print("sample:", type(image).__name__, image.size, label, classes[label])

display_transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5)),
])
display_dataset = CIFAR10(
    root="data", train=True, download=True, transform=display_transform
)
display_loader = DataLoader(
    display_dataset, batch_size=8, shuffle=False, num_workers=0
)
sample_images, sample_labels = next(iter(display_loader))
figure, axes = plt.subplots(2, 4, figsize=(10, 5))
for axis, sample_image, sample_label in zip(
    axes.reshape(-1), sample_images, sample_labels
):
    display_image = (sample_image * 0.5 + 0.5).clamp(0, 1)
    display_image = display_image.permute(1, 2, 0)
    axis.imshow(display_image.numpy())
    axis.set_title(classes[int(sample_label.item())])
    axis.axis("off")
figure.tight_layout()
plt.show()

P2. 数据变换、CHW 与归一化

本节目标

把 PIL 图像转换为 [3,32,32] 浮点张量，并用逐通道 Normalize 把值域从 [0,1] 映射到约 [-1,1]。

理论连接

<p>PIL/NumPy 常按 HWC 排列，即 <code>[32,32,3]</code>；PyTorch 图像张量按 CHW 排列，即 <code>[3,32,32]</code>。<code>ToTensor</code> 同时把 8 位像素除以 255。</p> <p>每个通道执行 <code>x'=(x-mean)/std</code>。当 mean=std=0.5 时，0 映射为 -1，1 映射为 1。加入 batch 后形状为 <code>[B,3,32,32]</code>，进入 MLP 前再展平为 <code>[B,3072]</code>。</p>

P6. 实现 3072→512→256→10 的 MLP

本节目标

手写 MLP 类，逐层追踪张量和参数形状，并把线性变换、ReLU 与反向传播公式对应起来。

理论连接

<p>每个线性层仍满足 <code>A=XW^T+b</code>。隐藏层激活的 ASCII 映射是 <code>ReLU Z=max(0,A)</code>，MathJax 形式为：</p> <p class="math-display">$$ z_{bj}^{(l)}=\max\!\left(0,a_{bj}^{(l)}\right). $$</p> <p>b 是 batch 中的样本下标，l 是层号，j 是第 l 层隐藏节点下标；ReLU 对每个 a_{bj}^{(l)} 独立运算且不改变形状。数据流是 [B,3,32,32] → [B,3072] → [B,512] → [B,256] → [B,10]。</p> <p>下面先采用<b>单样本、列向量约定</b>。反向传播的 ASCII 映射是 <code>backprop dL/dW^l=delta^l(z^(l-1))^T</code>：</p> <p class="math-display">$$ \frac{\partial L}{\partial W^{(l)}}=\delta^{(l)}\left(z^{(l-1)}\right)^{\mathsf T}. $$</p> <p>在 mini-batch 的<b>样本按行</b>约定下，设 \(Z^{(l-1)}\in\mathbb{R}^{B\times n_{l-1}}\)，\(\Delta^{(l)}\in\mathbb{R}^{B\times n_l}\)，则 batch 平均梯度为：</p> <p class="math-display">$$ \frac{\partial L}{\partial W^{(l)}}=\frac{1}{B}\left(\Delta^{(l)}\right)^{\mathsf T}Z^{(l-1)},\qquad \frac{\partial L}{\partial w_{ji}^{(l)}}=\frac{1}{B}\sum_{b=1}^{B}\delta_{bj}^{(l)}z_{bi}^{(l-1)}. $$</p> <p>矩阵乘积的形状是 [n_l,B]×[B,n_{l-1}]=[n_l,n_{l-1}]，与 W^{(l)} 相同。l 表示从第 l-1 层到第 l 层；w_{ji}^{(l)} 的右下标 i 是来源节点，左下标 j 是目标节点；b 是样本下标。对 b 求和并除以 B，正好对应 batch 平均损失。</p> <p>本课只用全连接层和 ReLU，不引入 CNN、Dropout 或 BatchNorm。</p>

P7. 交叉熵损失与 SGD

本节目标

把 [B,10] logits 和 [B] 整数标签变成标量损失，并建立不含手动 Softmax 的 SGD 优化器。

理论连接

<p>多类交叉熵的 ASCII 映射是 <code>CE L=-(1/B) sum_b log y_(b,t_b)</code>：</p> <p class="math-display">$$ L=-\frac{1}{B}\sum_{b=1}^{B}\log y_{b,t_b}. $$</p> <p>B 是 batch 样本数，b 是样本下标，t_b 是第 b 个样本的真实类别下标，y_{b,t_b} 是样本 b 经 Softmax 后分给目标类别 t_b 的概率；一般类别下标 k 遍历 0…9。PyTorch 接收 logits 并在内部稳定地完成 log-softmax。</p> <p>随机梯度下降的 ASCII 映射是 <code>SGD W <- W - eta dL/dW</code>：</p> <p class="math-display">$$ W^{(l)}\leftarrow W^{(l)}-\eta\frac{\partial L}{\partial W^{(l)}}. $$</p> <p>l 是层号，W^{(l)} 是连接第 l-1 层到第 l 层的权重矩阵，eta 是学习率，偏导是当前 mini-batch 对这一层权重的梯度；每层偏置也按同类规则更新。</p>

本节目标

理论连接

<p><code>backward()</code> 用链式法则把标量 L 对每个参数的梯度写入 <code>.grad</code>。PyTorch 默认累加梯度，所以每个 batch 前必须清空。<code>step()</code> 只读取梯度并更新参数，不会自动计算梯度。</p> <p>每个 batch 的 <code>loss.item()</code> 已是 batch 平均值。最后一批可能较小，因此累计时用 <code>loss×batch_size</code>，最后除以总样本数，不能直接平均各 batch 均值。</p>

import torch

def train_one_epoch(model, loader, criterion, optimizer, device):
    model.train()
    loss_sum = 0.0
    correct = 0
    sample_count = 0
    for images, labels in loader:
        images = images.to(device, non_blocking=device.type == "cuda")
        labels = labels.to(device, non_blocking=device.type == "cuda")
        optimizer.zero_grad(set_to_none=True)
        logits = model(images)
        loss = criterion(logits, labels)
        if not bool(torch.isfinite(loss).item()):
            raise FloatingPointError("non-finite training loss")
        loss.backward()
        if not all(
            p.grad is not None and bool(torch.isfinite(p.grad).all().item())
            for p in model.parameters()
        ):
            raise FloatingPointError("missing or non-finite gradient")
        optimizer.step()
        batch_size = labels.size(0)
        loss_sum += float(loss.item()) * batch_size
        correct += int((logits.argmax(dim=1) == labels).sum().item())
        sample_count += batch_size
    if sample_count == 0:
        raise ValueError("empty training loader")
    return {"loss": loss_sum / sample_count,
            "accuracy": correct / sample_count,
            "samples": sample_count}

</details>

逐行与变量解释

<ol><li><code>model.train()</code> 明确进入训练状态。</li><li>每批 images[B,3,32,32]、labels[B] 移到参数所在设备。</li><li><code>zero_grad(set_to_none=True)</code> 清除上一批梯度；forward 得 logits[B,10]；criterion 得标量。</li><li><code>loss.backward()</code> 填写每个参数同形状的 grad；有限性检查可尽早发现数值错误。</li><li><code>optimizer.step()</code> 执行参数更新。</li><li>用当前 B 加权损失并累计正确数；最终三个指标都对应同一 <code>sample_count</code>。</li></ol>

预期输出

例如第 1 个 epoch 可能得到 {'loss': 2.1..., 'accuracy': 0.2..., 'samples': 8000}；数值仅示意，不承诺准确率。

常见错误

<ul><li><b>忘记 zero_grad：</b>梯度跨 batch 累加，更新方向错误；放在每次 forward 前。</li><li><b>忘记 backward：</b><code>step</code> 没有新梯度可用。</li><li><b>直接平均 batch loss：</b>最后一批权重被放大；按 batch 实际样本数加权。</li><li><b>loss 变 NaN：</b>先降低学习率，再检查输入和梯度是否有限。</li></ul>
