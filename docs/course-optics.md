# 光学期中复习资料

本资料覆盖当前已有五份课堂课件，共205页，按“光怎样描述、怎样产生、怎样传播”组织。复习时先理解物理量和假设，再独立重现推导，最后用自测检查是否会判断公式的适用范围。

## 统一符号

使用SI单位。复表示为 $\mathbf E(\mathbf r,t)=\operatorname{Re}[\mathbf E_0e^{i(\mathbf k\cdot\mathbf r-\omega t)}]$，$E_0$ 在标量或线偏振情形表示峰值而非有效值；一般复向量还编码分量相位，其模平方为各分量模平方之和。$\nu$ 是普通频率，$\omega=2\pi\nu$，$k_0=\omega/c$，$\lambda_0=c/\nu$。$\varepsilon_r,\mu_r$ 是相对参数；未带下标的 $\varepsilon,\mu$ 在本资料公式中表示绝对参数。

被动吸收介质取 $\widetilde n=n_r+i\kappa$，$\kappa\ge0$。课件或旧电动力学笔记若采用另一时间因子，应整体变换复数符号，不能只抄虚部正负号。黑体频谱与Einstein系数以普通频率 $\nu$ 定义；改变为角频率时必须变换谱密度。

## 使用方法

第一遍沿四章阅读，遇到公式先写出“研究对象、假设、所求量”。第二遍遮住推导，从Maxwell方程、振子方程、热平衡或往返条件重新推一次。第三遍做每章自测，再通过公式速查纠正错误。能记住结论还不够，应能解释因子 $1/2$、$2\pi$、折射率 $n$ 和波长的真空/介质区别来自哪里。

课件中的推导省略或约定不清处，在对应正文说明。用于建立关联的电动力学笔记是辅助资料，其公式仍需检查单位、时间约定和适用条件。原始课件与旧笔记保持原样。
