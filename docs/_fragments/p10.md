**目的：**先用小规模确定性子集验证下载、设备、维度、反向、保存和绘图。

脚本快速模式默认 **3 个 epoch**，完整模式默认 20 个；Notebook 的顶层开关与运行预算以其自身配置为准。复现历史的一轮设置需要显式传入 `--quick --epochs 1`，不会因为页面改写改变训练默认值。

不下载数据的最小检查：

```sh
python public/downloads/cifar10_mlp_tutorial.py --smoke
```

真实数据训练（下载后在本机运行，预算由你设置）：

```sh
python public/downloads/cifar10_mlp_tutorial.py --quick --epochs 1
```
