# 大地测量

地面上的一个点可以用经纬度表达，也可以用三个直角坐标表达，但这些数值只有放进明确的地球模型和参考框架，才能表示可比较的位置。大地测量研究的正是这些表达、观测与地球真实形状之间的关系。

课程以《大地测量 绪论》和《椭球面数学性质》为两个主章。绪论说明研究对象、位置表达和观测方法；椭球章从一般曲线和曲面的工具出发，逐步推导旋转椭球上的坐标、方向、曲率、弧长与面积。其余四份资料用于补充解释和核对。

## 阅读约定

默认读者掌握基础微积分和线性代数，曲率与曲面概念仍从定义讲起。角度参与微分、积分和三角函数计算时使用弧度，交互输入以度显示。正文中的 $M,N$ 表示曲率半径，图中同名点由图注区分。

当前版本专注连贯讲解，不设置习题或自测。小算例帮助理解几何关系，学习标记保存在当前浏览器。原讲义与配图位置见[来源索引](geodesy-sources.html)，坐标旋转补充见[辅助说明](geodesy-rotation.html)。
