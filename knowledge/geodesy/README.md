课程按六章与辅助篇编排。每页先读几何图和例题，再展开详细推导；在专题末尾完成简短自测。个人随记可放在“学习笔记”文件夹，不进入网站课程页面生成流程。正文修改保存在 lessons 中，再运行网站生成命令。

## 统一约定

| 符号 | 约定 |
|---|---|
| B、L、h | 大地纬度、经度、椭球高 |
| M、N | 子午、卯酉曲率半径 |
| E、N、U | 东、北、上坐标分量，右手系 |
| A | 从北向东计的方位角 |
| 内部角度 | 弧度；图形输入另注度 |
| 旋转 | 明确主动／被动、源系／目标系和乘法次序 |
