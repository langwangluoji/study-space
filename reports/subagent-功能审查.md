# 独立子代理功能审查

本报告区分实测问题与后续建议。独立浏览器脚本为 `reports/subagent-function-audit.cjs`，原始结果为同目录 `subagent-function-audit.json`；不替代全站构建、数学或标准 UI 检查。

最终复测：2026-10-11，稳定预览 `http://127.0.0.1:8784/study-space/`，31 组独立检查通过，未发现未解决的功能缺陷或浏览器运行异常。

## 初次检查发现

已复现旧学习记录无法取消：当 `ml-course-progress-v1` 保存 `{"lecture-1:a1":true}` 或与 `a1:false` 并存时，取消“已读 A1”后刷新，旧的页面限定键仍把勾选状态恢复为真。影响旧记录迁移后已读状态的修改。原因是读取用逻辑或回退，而保存仅修改当前知识点键。建议按“当前键存在则采用当前值，否则读取旧键”明确优先级，保留其他记录。

该问题已修复并独立复测：当前 `a1:false` 优先于旧别名的真值；只有旧别名的记录仍正确导入，取消勾选后刷新保持未读，其他知识点记录不受影响。

初始第二讲右侧大纲有 49 项，第三讲有 67 项，包含重复“符号与推导”和默认关闭附加框中的大量细节标题。这是阅读结构问题，交由主代理统一调整。

最终第二、三讲大纲各为 3 段主线，旧的知识点锚点与附加框锚点继续可用。

## 已验证的功能

- 首页能进入课程总览，课程总览能跳到第二讲 B1；SPA 路由切换保留主题。
- A1–A15、B1–B6、C1–C5、P0–P15 共 42 个旧主锚点存在。
- 三讲共 26 个互动图可通过键盘调节滑块，图像或读数随之改变。A6 的说明文字固定，但画布随参数变化，测试已按画布内容比较而非强求说明文字变化。
- 直接访问折叠框中的 C5 数值复算锚点会展开祖先框，标题出现在可阅读位置。
- 搜索无结果时显示中文反馈。
- 390 px 资料页、320 px 教材页无整页横向溢出；PDF 保留页码与直接下载入口。
- 教材、三讲 PDF/PPTX、Notebook、两个 Python 文件与运行标记保持原访问路径。

完整结果与最后复测状态以原始 JSON 为准。

## 可选改进意见

1. 互动图的滑块标签统一为“调整图中参数”，可逐图改成实际参数名称，例如学习率、间隔或激活输入，让读者在拖动前知道在改变什么。现有图形与读数响应正常，这属于教学可用性建议。
2. 第二、三讲每段主线末尾可以给一两句连贯的“本段得到什么、下段为什么需要它”，并提供可展开的符号速查。保持正文连续，避免再添加大量编号与清单。

移动端大纲 Escape 初测只在按键后立刻检查，存在退场动画时序干扰；等待退场后最终复测已确认正常关闭，不是网站缺陷。

这些建议不是本轮已完成的全部改动，也不应视作已经验证存在的数学错误。
