# 光学：课程学习与考试复习

光学用场描述光的传播，用物质与场的相互作用解释发光、吸收和色散。波动、光源、激光和介质响应由此连成一门课。

## 选择阅读版本

| 版本 | 内容 | 入口 |
| --- | --- | --- |
| 课程内容学习版 | 概念解释、完整推导、算例与电动力学联系 | [进入课程学习版](optics-learning.html) |
| 考试复习精简版 | 29 个概念问答、主要公式、适用条件与解题起点 | [进入概念公式精简版](review-optics.html) |

学习新内容时，沿课程学习版逐章推导；考前复习时，从精简版检查概念和公式，遇到不熟悉的步骤再回到对应主章。
