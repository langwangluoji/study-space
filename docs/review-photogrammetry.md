# 摄影测量 · 期末关键速查

计算前先写四项：**像方还是物方、采用什么坐标轴、谁是观测/已知/未知、公式在什么条件下成立。** 本页只留关键关系与做题顺序，详细推导看[连续讲义](./course-photogrammetry.md#shared-case)，原四页复习纸与逐项勘误见[详查页](./photogrammetry-review.md)。课堂潘第三版与王书章号不同，原件定位见[实际来源](./photogrammetry-sources.md#pan-classroom)。

## 先固定坐标与单位 {#conventions}

地面Z向上；$R$表示相机→地面，$q=R^T(P-C)$。地面点低于相机时$q_z<0$；等效像面取$z=-f$：

$$x-x_0=-f\frac{q_x}{q_z},\qquad y-y_0=-f\frac{q_y}{q_z}.$$

像方$f,x,y$同用mm；物方坐标同用m，两个物方分量的比值无量纲。$q_z=0$时有限像点不存在。像元10μm=0.01mm；规则网格$x=(c-c_0)a$，$y=-(r-r_0)a$，注意图像行向下。$R^T$与$R$不能互换，摄影中心$C$不等于计算机视觉中的$t=-R^TC$。详见[4.2–4.5](./photogrammetry-en-04.md#e4-2)。

## 六组关系，连同条件记 {#formulas}

|任务|关键式|前提与最容易错的量|
|---|---|---|
|比例尺|$s=f/D=1/m$，$D=H_s-h$|近似正直、局部平地；把f转m再与D相除。大m表示小比例尺|
|GSD/覆盖|$\mathrm{GSD}=Da/f$，$W=wD/f$|a与f同单位；GSD不是实际分辨率，也不是坐标准确度|
|重叠|$B=W(1-p_x)$，$D_y=W_y(1-p_y)$|区分摄影基线B与旁向航线间隔$D_y$；重叠用小数|
|起伏位移|$d=rh/H$；若用基准点像距$r_0$则$d=r_0h/(H-h)$|竖直摄影；r指高点到主点像距，H相对同一基准面；倾斜不能直接套|
|理想双像视差|$p=x_L-x_R=fB/(H-h)$；$h=H-fB/p$|等高、光轴平行竖直、同主距同像轴、已校正像对；绝对视差p不是两点视差差Δp|
|视差精度传播|$\sigma_h\simeq fB\sigma_p/p^2=D^2\sigma_p/(fB)$|小误差；暂把f/B/H当精确；独立左右各$\sigma_x$时$\sigma_p=\sqrt2\sigma_x$|

理想双像中比较**同一点**的基线效果，B变时p也随之变；固定p只改B就是换了点。共面/核线约束只筛候选，同名点仍可因重复纹理选错。[视差条件与推导](./photogrammetry-en-02.md#w4-hiehbf4)。

## 遇到不同题型怎样下手 {#steps}

**尺度、航高与航摄规划。** 先认清题给的是摄站高程还是离地距离，统一单位求D；由像幅算地面W，再算B与旁向间隔。最后画首末摄站及足迹区间，检查边缘要的是单覆盖、立体覆盖还是保护外扩，再取整计数。$L/B+1$不是脱离边界条件的万能片数式。[边界算例](./photogrammetry-en-02.md#w3-h1jvek6f)。

**高差/建筑高。** 先画顶、底及基准面，标明给定r属于顶还是底；判断是单像径向位移还是双像视差。若题用视差差近似式，必须说明参考面及“像片基线”b的含义，不能将其直接当两点各自的绝对p。近似与严格比值模型的输入定义一致才可比较。

**单像后交。** 已知控制点XYZ、像点xy和内方位，待求相机六外方位。正投影→量测减预测→线性化Jacobian→加权最小二乘改正→更新→检查收敛、控制布局与残差。观测数量够不保证几何满秩；旋转向量与欧拉角偏导不可混用。[完整六参数例](./photogrammetry-en-05.md#w5-s52-example)。

**前交与反投影。** 前交已知两相机与对应像点，求XYZ；一条射线则还需平面/DEM条件。有噪两射线一般不相交，先声明求最近线中点还是最小重投影误差。DEM多交点要选首个可见交点。[单射线](./photogrammetry-en-05.md#e5-4) · [双射线](./photogrammetry-en-05.md#e5-5)。

**相对、绝对与光束法。** 相对定向确定两片相对几何的五自由度，保留整体尺度与基准；绝对定向用$P=t+\lambda R_gP_m$安放模型，七参数，λ单位是地面长度/模型长度。光束法直接共同求相机与点，必须有基准约束；Schur消去点未知只改变求解组织，不丢观测。[五阶段工作单](./photogrammetry-en-05.md#task-ledger)。

**光学与像质。** 薄透镜$1/f=1/u+1/v$；光圈数$N=f/A$，小N为大孔径。模糊、几何畸变、采样与像移分开判断：像移近似$\Delta x=(f/D)Vt$，随后除像元尺寸得到模糊像元数。近似前声明正直、匀速、短曝光。[传感系统](./photogrammetry-en-03.md#e3-2)。

## 收尾必须回答的质量问题 {#quality}

**精密度**是模型内随机不确定度；**准确度**靠外部独立检查；**可靠性**关注错量是否有机会被发现。控制点拟合好、像方残差小、核线残差为零，都不足以单独证明真实地面坐标正确。独立检查$\mathrm{RMSE}=\sqrt{\sum e_i^2/n}$，报告分量、样本数和单位；一个检查点只报偏差，不包装成总体统计结论。

DEM/DTM表达地面表面，DSM含建筑/树冠；DOM用选定表面将地图格点回投原影像取色。双线性插值是四邻域加权：$g=(1-u)(1-v)g_{00}+u(1-v)g_{10}+(1-u)vg_{01}+uvg_{11}$，不提高原始分辨率。裸地DEM不会自动纠正屋顶位移，遮挡还需检查。

最后用共同案例自测：f150mm、H1000m、B300m、左(30,15)、右(−15,15)mm，应得到P=(200,100,0)m、p45mm；$\sigma_p=5$μm时$\sigma_h\approx0.111111$m。230mm方幅覆盖1533.333m、重叠80.4348%；换36mm方幅后左点已出片，不能继续假装有有效同名点。
