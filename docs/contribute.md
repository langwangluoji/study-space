# 让资料变成可持续维护的知识

一门课程可以同时有教师课件、教材、个人笔记和实践代码。本站把它们组织成连贯的解释，并保留“这个结论来自哪里、为什么这样写、哪些内容还没整理”的线索。

## 从新来源到知识章节

1. **确定课程范围。** 先记录来源标题、作者、版本和获取方式，判断它补充哪个问题或章节。
2. **建立知识对应。** 按概念和推导组织章节，记录来源页码；同一问题的多份资料放在一起比较。
3. **处理差异。** 说明符号、条件或结论的不同；勘误写进正文并给出依据，保留原文件。
4. **形成阅读主线。** 先提出问题，再解释符号和推导；扩展证明和代码可以按需展开。
5. **核对后接入。** 检查公式、资源路径和显示，把课程入口、章节和资料目录一并更新。

## 给一份资料补全信息

每份资源至少记录所属课程、类型、标题、作者、用途和公开状态。教材补充版本与章节；课件补充文件页码；代码说明环境、执行方式和结果边界。只有已经提供的文件显示站内下载，尚未公开的原件标为“仅本地存档”。

资料目录由统一资源清单维护，课程首页与课程目录共享课程清单。这样增加一个资源时，不必重复修改多个页面。具体文件、字段和构建命令见[详细维护指南](read-README.html)。

## 修订已有知识

保持已有章节链接和锚点可用，先找到具体知识段，再修改解释与对应出处。影响数值计算的变更需要复算；界面调整核对导航、搜索、手机排版和资源获取。已保存的历史实验结果保留原口径。

发现问题时，可以在[网站仓库](https://github.com/langwangluoji/study-space)提交带页面地址、问题位置、依据和建议的 Issue，或通过 Pull Request 提交修订。

## 当前范围与下一步

目前提供机器学习前三讲及 CIFAR-10 实践、大地测量绪论及椭球数学性质。课程清单是导航入口，新增课程仍需提供章节正文、来源对应和课程导航。网站不把尚未整理的课程显示成已完成，也不自动把上传资料变成经过核验的知识。

遥感原理与基础作为下一门课程，待内容与来源整理完成后接入同一课程目录和资料库，沿用资料预览、下载、来源对应与复习入口。现阶段不把未完成的遥感知识正文展示为已完成课程。

完整的修订过程可以保存在仓库中，构建时检查资料清单与内部链接；[内容核验记录](verification.html)说明已有内容的核对范围。
