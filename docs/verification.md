## 数学口径

平方损失统一为每样本平均半平方误差，残差为预测减目标；分类损失按样本平均。单样本网络使用列向量，批量使用行布局。分类线性模型按类别存权重列，网络连接按目标节点存权重行，转换时显式转置。

概率用随机目标 $T$ 与观测 $t$ 区分；期望与协方差说明随机性来源。高斯方差、秩、独立抽样、共享协方差、可分间隔及光滑邻域等必要条件保持可见。

## 自动核验

运行 `npm run check` 核对缺失片段、标题配置、内部资源与锚点；构建时渲染数学并检查错误标记。运行 `npm run check:math` 独立复算：

- 回归样章、正规方程与新 ReLU 网络的前向、梯度和一步更新。
- 中心差分的多个步长，以及单样本、批量的 PyTorch float64 自动微分。
- 投影、协方差、后验二次型、Fisher 与特殊标签最小二乘等价。
- Logistic 参数梯度和 Hessian、Softmax 参数梯度与 Jacobian。
- 完整可运行 NumPy 片段及不下载 CIFAR-10 的合成输入 SGD smoke。

`scripts/check-ui.cjs` 检查 1440、390、320 像素下的深浅主题、附加框、局部公式滚动、搜索定位、路由切换和旧学习记录。机器记录保存在仓库 `reports/` 中；数学数值核验补充一般推导，不能代替定理证明或证明读者已经理解。
