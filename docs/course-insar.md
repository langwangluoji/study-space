# InSAR 原理与应用

从一束发出的微波开始，跟踪它怎样与地物相互作用、怎样被处理成图像，再辨认图像中的几何、明暗和相位分别告诉我们什么。这三章按教师已经提供的三讲组织，为后续干涉测量建立共同的信号与几何基础。

这里以基础微积分、复数和向量为起点；需要的新概念会在使用前解释。先读正文建立联系，再展开算例和推导。课件图保留原内容，关键公式用可放大的示意图解释，正文中的条件不藏在附加框里。

一条共同主线是：**散射决定回波，成像处理组织回波，解译在几何和统计条件下解释图像**。后续 InSAR 再把两次可靠的复数观测联系起来，利用相位差约束路径差。

## 阅读时始终固定的对象 {#conventions}

本站用 $R$ 表示雷达到目标的单程斜距，$\lambda$ 表示波长，$\theta$ 表示相对于平地法线的入射角。复数像元记为 $s=Ae^{i\phi}$；幅度为 $A$，强度为 $|s|^2$。接收基带传播相位采用 $-4\pi R/\lambda$ 的约定。

角度、差分顺序和距离方向会决定公式中的符号。阅读推导时先确认这些约定，再比较不同教材；符号相反不自动意味着结论错误。具体关系见[公式与概念索引](insar-review.html)。
