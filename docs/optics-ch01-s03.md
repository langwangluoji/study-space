# 1.3 光学内容与课程体系

<span class="optics-key">学习重点</span> 先读本节的概念、模型条件与课件图，再按需展开推导。

## 课程的六个问题

![从光学现象通向描述、重要性、特点和研究内容的学习图](/optics/figures/nov05-course-learning-map-p03.png)

《光学202609-波动.pdf》PDF第3页（局部）。从中心的光学现象沿四条支路阅读：先准确描述现象，再说明其重要性、提炼特点，最后确定研究内容。四条支路给出本章的学习任务；将具体实验或生活现象放入中心，即可据此组织现象、物理问题与模型的联系。


![几何光学、波动光学、矢量光学和量子光学的嵌套示意](/optics/figures/nov05-course-model-hierarchy-p02.png)

《光学202609-波动.pdf》PDF第2页（局部）。从内向外看几何、波动、矢量、量子四个层次：光线模型适合研究路径，标量波描述相位与干涉，矢量场进一步描述偏振，量子理论讨论光子及物质能级。嵌套表示本课件的模型层次和适用内容扩展，圆的面积没有定量含义；几何光学通常来自短波极限。


![由光的本性、产生、传播、探测、物质作用和应用构成的课程问题链](/optics/figures/nov05-course-logic-p01.png)

《光学202609-波动.pdf》PDF第1页（局部）。从上到下读六个问题：光是什么、怎样产生、怎样传播与调控、怎样探测、怎样与物质相互作用及怎样应用。右侧括号把这些问题连成课程的逻辑体系；每个小照片只作问题实例，知识主线由问题之间的关系给出。


PPT导论把光学组织为六个相互联系的问题：光如何产生，光是什么，光怎样传播与调控，光怎样探测，光怎样与物质相互作用，光怎样应用。学习每一章时，先把模型放回这个过程：光源提供输入，传播和界面改变场，探测将场转成观测量。

<span class="optics-key">核心结论</span> 同一个光学过程可以需要不同层次的模型。几何光学跟踪光线，波动光学追踪振幅与相位，矢量描述电磁场方向，量子描述能量交换。选用模型的依据是问题的尺度、观测量及适用条件。

## 用课程体系组织后续章节

第2章建立波函数语言，第3章把光接到电磁理论与光子描述，第4—6章研究光源与辐射，第7—8章研究介质中的传播与叠加，第9章研究界面的反射、折射和偏振调控。

这份PPT提供的是1.3导论与总结页。本节据这些页组织课程概览；后续若补入1.1、1.2原课件，可按原节号继续扩充。
