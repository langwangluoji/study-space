# 第四单元 · 共线方程

## 先把空间点表达成相机看到的方向

设物空间点 $P=(X,Y,Z)^T$，摄影中心 $C=(X_s,Y_s,Z_s)^T$。先减去中心得到 $P-C$，再将这个向量转到相机轴系。本页使用 $R_{wc}$ 表示 **world → camera**：

$$q=R_{wc}(P-C)=(q_x,q_y,q_z)^T.$$

中文教材 PDF 52 的 $R$ 表示 camera → 辅助轴系。若物方与该辅助轴系平行，则这里的 $R_{wc}=R^T$。旋转矩阵满足 $R^TR=I$、$\det R=1$，因此 $R^{-1}=R^T$；任意矩阵不具备这一性质。

摄影中心坐标 $C$ 也不同于计算机视觉表达中的 $t$：若 $q=R_{wc}P+t$，则 $t=-R_{wc}C$。不能把两种写法中的平移量直接替换。

## 三点共线怎样消去深度尺度

像向量为 $i=(x-x_0,y-y_0,-f)^T$。物点向量 $q$ 与它平行，可以写 $i=\lambda q$。第三个分量给 $-f=\lambda q_z$，于是

$$x=x_0-f\frac{q_x}{q_z},\qquad y=y_0-f\frac{q_y}{q_z}.$$

这里消去的是沿视线的比例因子，不是“空间深度不重要”。深度以分母的形式决定横向位置相对成像的缩放。$q_z=0$ 时有限像坐标不存在，不能继续除法。

若 $R_{wc}$ 的行记为 $r_1^T,r_2^T,r_3^T$，标量形式是

$$x-x_0=-f\frac{r_1^T(P-C)}{r_3^T(P-C)},\qquad y-y_0=-f\frac{r_2^T(P-C)}{r_3^T(P-C)}.$$

> 原创学习句：**The collinearity equations connect image coordinates, object coordinates, and camera parameters.** 一套物理关系可以服务不同任务，区别在于哪些量已知、哪些量待求。

## 从最简单的情况验证符号

取 $R_{wc}=I$、$x_0=y_0=0$，并使用相机局部 $+Z$ 指向被摄场景、真实像平面在 $z=-f$ 的约定。物点相机坐标 $(20,0,100)$ m，$f=0.15$ m，则 $x=-0.03$ m $=-30$ mm。负号来自倒立的真实像面。

<PhotogrammetryLab type="collinearity" />

实验使用与上式匹配的局部深度轴；它的“高度”先转成到地面的正深度 $H-h$。实际世界高程常以向上为正，需在旋转中处理这两种轴向，不能把局部深度直接当世界高程。

物点变成 $(40,0,200)$ m 时，$X/Z$ 保持 0.2，仍投到 $-30$ mm。这一数值例子再次说明单像逆解深度不唯一。如果已知地面高程或地表模型，可以用射线与地表求交；如果只有像点，没有这个附加条件，就不能恢复唯一物点。

## 同一模型的三种用法

|任务|给定什么|求什么|
|---|---|---|
|正投影|物点、相机内外方位|预测像坐标|
|后方交会 / resection|控制点地面坐标、像坐标、内方位|摄影中心与姿态|
|前方交会 / intersection|多个像点、相机内外方位|物点三维坐标|
|光束法 / bundle adjustment|许多像点和控制信息|多台相机与多个点共同估计|

后两类不能靠逐项代入直接解出全部未知。共线方程对姿态和物点是非线性的，需要初值、线性化和迭代，这将在区域网单元解释。

<details><summary>为什么把旋转矩阵抄对了，计算仍可能出错？</summary>

矩阵必须有变换方向。camera→world 的矩阵如果直接用于 world→camera，就少了转置；角度顺序、左右手轴和正/负像面约定也必须一致。先检验 $R^TR=I$，再用已知姿态做投影与反投影闭合。

</details>

<details><summary>把 $P-C$ 乘两倍，预测像点会怎样？</summary>

在这个单相机理想模型中，各分量同时扩大两倍，比值不变，像点不变。但沿视线的物点距离改变了；这不是在说真实物体坐标相同。

</details>
