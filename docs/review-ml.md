## 用一组数字串起第一讲

$x=[-1,0,1,2]$，$t=[0,1,1,4]$。初值 $(w_0,w_1)=(0,1)$ 时，$r=[-1,-1,0,-2]$，$L=0.75$，$\nabla L=(-1,-0.75)$。正规方程解为 $(0.9,1.2)$，$r=[-0.3,-0.1,1.1,-0.7]$，$L=0.225$，且 $X^Tr=0$。

列空间正交发生在样本空间中，不是二维散点到直线的垂距。[打开校准架复算](lecture-1.html#a3)。

## 最容易丢掉的条件

- 概率模型需说明独立性、噪声形式和方差约定。平方风险的条件均值结论需要适当有限二阶矩，不要求高斯。
- 先划分数据，再用训练部分拟合标准化等统计量；测试集不能参与挑配置。
- HOG 改参数后重新计算维数，并修改 MLP 输入层；相同维数不代表相同表示。
- 快速模式核验流程；正式性能来自记录完整设置的真实训练。
