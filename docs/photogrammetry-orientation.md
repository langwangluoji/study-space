# 第六单元 · 交会与定向

## 先把已知与未知写出来

后方交会（space resection）用已知控制点坐标与它们的像点观测求相机位置和姿态。内方位已知时，单相机有六个外方位未知数，每个控制点提供两条像坐标方程。三个点仅满足方程计数，可能存在多解或退化；实际需要冗余、分布良好的控制及合理初值。

前方交会（space intersection）用已定向影像中的同名像点求一个物点的三维坐标。两张影像提供四个像坐标观测，对三个点坐标有一项计数冗余；设计矩阵是否满秩、交会角是否足够，仍需另查。

> 原创学习句：**Resection finds the camera. Intersection finds the object point.** 这里 resection 是测量术语，不能按日常英语理解成外科切除。

## 同一个点的两条射线

把相机向量旋转到共同物空间，写两条射线

$$P=C_1+\lambda_1q_1,\qquad P=C_2+\lambda_2q_2.$$

理想数据能够在一致位置相交；实际数据常使两线偏斜。课程中按 XZ 分量求两个尺度，再平均 Y，是特定近似解法；最小化物方射线距离与最小化像方重投影残差也不是完全相同的目标。应依据观测误差模型选择估计方法。

基线短或射线夹角小，轻微像点误差就会导致很大的深度变化。用观测数量足够来代替网形检查，会得到看似有解但精度很差的结果。

## 两条重建路径

|路径|步骤|需要的外部信息|
|---|---|---|
|先求相机|内定向 → 分别后方交会 → 前方交会|足够的地面控制坐标|
|先建自由模型|内定向 → 相对定向 → 模型交会 → 绝对定向|先靠同名点建模型，再靠控制接地面基准|
|联合估计|初始几何 → 多像光束法平差|影像连接与相应基准约束|

并不是所有任务都必须“后交→相对→绝对”顺序走完。理解每一步输入输出，比背操作清单更重要。

## 相对定向：恢复两束光的相对位置

已标定双像在固定坐标自由度和任意尺度后，相对定向（relative orientation）有五个独立自由度：相对旋转三个，加基线方向两个。基线长度提供尺度，但仅凭双像内部几何不能求出真实尺度。

每对同名点提供一个共面条件，最少五对是计数条件，不保证唯一与稳定。传统课程常用六个标准定向点；数字流程采用更多分布良好的匹配点。通过消除上下视差（y-parallax）恢复立体模型，并不等于已经把模型放进国家坐标系。

连续像对定向常固定左片，以 $(B_y,B_z,\varphi_2,\omega_2,\kappa_2)$ 表示五参数；单独像对方法把基线选为 X 轴，采用另一组五角参数。参数组合随约定改变，但共同目标是恢复相对几何。

## 绝对定向：给模型尺度和地面基准

三维相似变换（similarity transformation）把自由模型接入地面坐标：

$$P_g=\mu R P_m+t.$$

七参数是一个统一尺度 $\mu$、三个旋转和三个平移。统一尺度保留形状与角度；分别拉伸 X、Y、Z 不是同一类相似变换。Absolute 表示相对于目标坐标系，不表示没有误差。

中文教材 PDF 99 明确写了课程传统控制条件：至少两个**平高控制点**加一个高程点，且三个点不能在一条直线上。期末纸简写“两个平面点加一个高程点”不能直接替代该条件。通用数值理解可以先用三个不共线的完整三维对应点；真实生产还应增加冗余和良好布设。

若模型坐标两点相距 10 个模型单位，地面同两点相距 25 m，则尺度为 $\mu=2.5$ m/模型单位。确定尺度还不够，整体仍要旋转和平移，才能落到正确位置。

<details><summary>模型整体扩大两倍、两台相机中心也扩大两倍，预测像点会改变吗？</summary>

在没有外部尺度约束的校准模型中，射线方向比例不变，因此像点不变。这就是尺度不确定性的几何原因；要得到米制尺度，需要控制点、已知长度或其他尺度信息。

</details>

<details><summary>六个外方位参数、五个相对参数、七个绝对参数为何不矛盾？</summary>

它们求解的对象与固定的自由度不同。六个描述一台相机在既定物空间的位置姿态；五个描述无尺度的双像相对几何；七个把一个任意尺度模型整体变换到目标坐标系。

</details>
