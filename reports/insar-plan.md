# InSAR 前三章实施计划与进度

基线：现有 Study Space 的 VitePress 1.6.4，GitHub main 合并 PR #7 后内容与本地 fdb6fa8 内容树相同。采用独立 checkout 和 feat/insar-foundations 分支，避免同时进行的遥感工作修改相同文件。

1. 固定来源：四 PDF 保持原件；抽取三份课件全文；扫描课本视觉读取封面、目录和相关页。
2. 组织主线：按课堂三讲，而非课本章号。共同约定单程 R、从法线量 θ、接收基带负相位和干涉差分顺序。
3. 分工：三子代理分别负责三个正文及自绘图，根负责教材补核、原图、统一索引、目录接入、网页端审阅和最终验证。
4. 插图：九张课件原页渲染及各章 SVG；保存来源、文件页、尺寸和 SHA-256；图可放大，主要公式邻近配图。
5. 接入：课程清单、专属导航、资料中心、自学/复习路线、全站搜索与连续阅读。
6. 核验：数学关系与算例、来源覆盖、Markdown/MathJax/内部链接、桌面/移动及深浅主题、配图对话框、搜索与资源筛选。
7. 交付：本地可维护正文和资源，GitHub PR；完成必要核验后按已授权的网站扩充范围上线并核验真实发布状态。

网页双端环节只提交本任务资料摘录和计划，不上传整份扫描书或无关文件；保存实际回答与采用/修正/拒绝结论。正文不出现工作交接流水。
