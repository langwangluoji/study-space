## P8｜训练循环的顺序不能乱 {#p8}

[↗ 第三讲：前向、反向、更新](lecture-3.html#c4)

<strong>目的：</strong>每批完成清梯度、前向、损失、反向与更新。PyTorch 的反向计算会把导数加到已有梯度中；本实践每批独立更新，因此先清除上一批的梯度，再计算本批损失，收齐梯度后才更新参数。



<strong>通过：</strong>若每个 batch 的 `loss` 是该批样本的平均损失，累计 epoch 损失时应先乘本批样本数，再除以整轮总样本数。这样最后一个较小 batch 不会与完整 batch 获得相同权重。

<strong>常见错：</strong>忘记清梯度。
