## 勘误与适用条件 / Errata and conditions {#rs-sources-errata}

<div class="rs-lang" data-rs-lang="zh" lang="zh-CN">

原文件保持原样。网页修正表述并解释条件，保留下面的原文定位；“在原稿中发现”与“科学修订依据”分开记录。

| 原定位 | 问题 | 正文处理 |
| --- | --- | --- |
| 第2章1页 | “电磁幅射” | 规范为电磁辐射 |
| 第2章27页、第4章24页 | Stephen Boltzmann；谱量与总量混用 | Stefan-Boltzmann；全谱出射度M=σT⁴，与Mλ分开 |
| 第2章28页 | 2898 mm K | 2898 μm K，等价2.898 mm K；波长形式谱峰 |
| 第2章30页 | 瑞利-金斯谱变量/量纲不清 | 用明确的Bλ或Bν，说明长波低频条件 |
| 第2章32–35页 | 发射率与热惯量绑定，TB=εT泛化 | 区分热物性与辐射比值；热红外逆普朗克，微波RJ近似另注条件 |
| 第2章53、69页 | 米氏散射普适λ⁻²；朗伯方向分布 | 不使用普适幂律；朗伯辐亮度方向不变，强度余弦分布 |
| 第3章10、24–25页 | 静止条件缺失；光照角“始终相同” | 赤道圆形顺行同步；同类过境太阳时近似相同，季节角度变化 |
| 第3章50页 | Landsat8写ETM+ | OLI/TIRS，经USGS核查 |
| 第3章172–174页 | MODIS列在高光谱类别 | 按36个离散波段讨论多光谱，不以波段数量单独定义高光谱 |
| 第3章历史表、第4章20、80–85页 | “目前”状态、MSS版本及SPOT产品等级 | 明确历史型号/版本，不套用全部卫星或当前状态 |
| 第4章92页 | 太阳反射图被标为被动微波 | 不作微波主图；正文以概念表区分被动微波辐射计与主动雷达 |
| 第4章125–126页 | “镜面漫反射”；InSAR称相干雷达 | 分清镜面方向与后向散射；干涉、相干性、差分观测各自解释 |
| 笔记1页 | proximal=接触式；TIR800–1400nm；主动=全天候 | 近距离不必接触；常用窗口8–14μm不是全部TIR定义；天气依波长/系统 |
| 笔记4–5页 | FOV=幅宽、IFOV=分辨率；重访限同角 | 分开角量/长度/采样/可辨能力；一般重访与同几何重复观测分开 |

波谱边界、温度和历史仪器参数的近似口径在正文具体标明。没有独立核实的高分卫星详细指标不作为确定数值发布。疑似原稿公式不作为推导出发点；正文采用明确物理量、条件和单位的标准表达。

## 定义与任务核对来源 / Definition and mission references {#rs-sources-official}

- [CIE · Radiance](https://cie.co.at/eilvterm/17-21-049)、[Lambertian relation](https://cie.co.at/eilvterm/17-24-063)、[Planck law](https://cie.co.at/eilvterm/17-24-005)：辐射量及条件 / radiometric definitions and assumptions.

- [NASA SVS · Landsat scanning](https://svs.gsfc.nasa.gov/12754/)：扫描机制的官方动画参考 / instrument-scanning animation reference.
