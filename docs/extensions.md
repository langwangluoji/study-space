# 让每份资料，回答一个具体问题

正文读到哪里卡住，就从哪里补资料。这里按已收录课程整理阅读建议，把教材、课件、术语和代码接回知识主线。建议中的教材页码以各课程来源索引为准。

以下路线是按需补充，不要求读完整本教材。先用对应小节解决当前问题，仍有兴趣再扩展；没有原件时，也可以先读本站解释与来源说明，通过每张卡的返回链接继续学习。

## 把两份资料放在一起读

先确认两份资料讨论的是同一个对象，再比较符号、条件和结论。遇到差异时，记录“来源页码—各自前提—不同之处”，回到正文查看解释与勘误；不要只凭公式外观判断谁对谁错。

- **补基础**：先补当前推导用到的定义，再返回原章节。
- **看原图**：同时读图注、单位、文件页与正文说明，留意定性图和定量关系的区别。
- **接实践**：先看运行说明和输入输出，在线阅读代码后仍需在本地环境执行。

## 阅读入口与原件获取

“阅读入口”可能是 PDF 预览、代码阅读页或整理后的课程讲义。“来源说明 · 原件仅维护者存档”只提供出处、页码与使用范围，本站不提供完整原件下载。下载以[资料中心](resources.html)的获取状态为准；发现缺失或过期入口可通过[共建页面](contribute.html#feedback)反馈。
