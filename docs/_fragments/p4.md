## P4｜DataLoader 决定一次更新看多少样本 {#p4}

[↗ 第三讲：mini-batch 梯度](lecture-3.html#c3)

<strong>目的：</strong>DataLoader 把数据集分成一次送入模型的小批量（batch）；B 是这一批的样本数，一个 epoch 则是完整遍历训练集。训练集打乱，验证与测试不打乱；Windows 排错从 `num_workers=0` 开始。



<strong>通过：</strong>一批图像形状为 `[B,3,32,32]`，对应标签形状为 `[B]`。首维 `B` 表示这一批实际包含的样本数；最后一个 batch 若数据总数不能被 batch size 整除，`B` 可能小于配置的批大小。

<strong>常见错：</strong>把一个 batch 当一个 epoch。
