# 电脑端可展开目录

在课程讲义的 1100px 及以上视口加入固定左侧目录，正文保持约 680px。目录默认展开，章节可独立折叠，当前页面自动标记；可以切换本页大纲，或收起整个目录。收起后正文居中，固定的“展开目录”按钮可恢复，开关偏好保存在本机。专注模式临时隐藏目录，退出后恢复。

1100px 以下使用原有抽屉，支持 Escape、焦点返回与滚动解锁；目录不遮住正文。资料页继续使用原有资源导航。沿用既定课程展卷的蓝色、字型与细分隔线。

验证覆盖 1440、1280、1100、1024、390、320px 两种主题共 144 个页面组合，以及目录章节折叠、当前页面、正文间距、收起/重开、偏好恢复、Escape、专注模式和跨尺寸切换。完整结果见 `../design-implementation/ui-checks.json`。发布及线上核验另行记录。
