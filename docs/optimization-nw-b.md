# 附录B · 一个正则化过程

**A Regularization Procedure**

第19章的原始—对偶Newton系统可能遇到非凸曲率或秩亏，附录B给出一个具体的 inertia correction and regularization（惯性修正与正则化）过程。它修正的是**计算方向的矩阵**，不是给统计模型自动增加真实先验信息，也不是把一般非凸模型改写成全局凸模型。

## 惯性为什么比“能求逆”更有信息

对称矩阵的 inertia 是正、负、零特征值的个数。在原书的变量记号中，$n$是原参数数，$m$是不等式数，$l$是等式数；所求KKT矩阵的目标惯性为 $(n+m,l+m,0)$。它包含约束导致的负方向，不要求整个KKT矩阵正定。

零个数为零保证非奇异；恰当的正负个数进一步与约束切空间上的正定曲率相联系。对称不定分解能提供这些符号信息，因而可以在求方向时检测。只检查“没有报错”会漏掉矩阵虽可逆但曲率结构错误的情况。

原书式(19.25)用两个参数：$\delta I$加到Lagrangian Hessian，处理错误曲率；$-\gamma I$加入等式乘子块，缓解等式Jacobian秩亏带来的奇异。松弛相关的正对角块已有自己的结构，不是所有块都一律加同一个正数。

## Algorithm B.1 的过程与理由

先试 $\delta=\gamma=0$：若矩阵非奇异且惯性正确，直接使用方向，无需为了“更稳定”额外扰动。若有零特征值，原书采用与当前障碍参数 $\mu$ 相关的小 $\gamma$；曲率修正从上一迭代的 $\delta_{\rm old}$或一个小初值开始试。

每次分解检查惯性；未满足则加大 $\delta$，直到符合目标，再用该矩阵求原始—对偶步。利用上一轮的修正量作初值，是因为相邻迭代通常不需要完全不同的曲率修正，可以减少昂贵的重复分解。

附录给的具体常数如 $10^{-4}$、放大10倍和折半继承，是典型启发式选择，不是数学上唯一最优的参数。原文明确强调这些heuristics可能无法提供所有必要保护。真正的步还需第19章的正性、价值函数/filter、残差和参数更新机制。

## 不能由这个过程推出什么

过大的 $\delta$会抹去原Hessian中的有用二阶信息，让方向更像缩放最速下降，可能明显减慢近解进展。正则化处理计算系统，不证明原约束可行，也不证明目标全局最优。若一个方向来自不可观测状态或冗余约束，改变线性系统使它可解，不意味着数据已经提供相应信息。

需要同时核对矩阵修改量、原始系统残差和实际步接受结果。尤其在惯导/组合导航的奇异方向中，应区分模型基准、传感器信息与算法阻尼；在控制中应区分QP方向可算和原非线性轨迹可行。
