# 光学课程学习版

描述光，需要同时回答三个问题：场在时空中怎样变化，能量怎样从光源进入场，物质又怎样改变场。下面从波函数出发，逐步建立光源与传播模型。

## 从波函数到光的电磁理论

[第01章](optics-waves.html)先用随动坐标建立一维行波，再由相位读出传播方向、周期和速度。平面波、球面波和柱面波把传播几何带入同一波动方程；Maxwell方程进一步约束电场和磁场，给出横波性与能流。

计算时先叠加场，再求平均二次量。线性方程允许场相加，探测器记录的强度含有由此产生的交叉项。学完后，应能从复振幅写出干涉项，并说明偏振、相位相关性和探测时间怎样影响它。

## 从辐射量到光源的谱

[第02章](optics-incoherent.html)先区分通量、辐照度、辐射强度和辐亮度，再研究热平衡中的光谱。模式密度与量子平均能量相乘得到Planck谱；对谱积分得到总出射度，对每波长谱求极值得到Wien位移规律。

加速电荷和能级跃迁提供另外两条理解光源的路径。比较偶极辐射、同步辐射、轫致辐射和切伦科夫辐射时，分别追踪运动、能量来源和相位条件；比较线谱、带谱和连续谱时，则追踪能级结构与展宽。

## 从能级布居到相干放大

[第03章](optics-laser.html)从吸收、自发辐射和受激辐射的速率开始。热平衡给出Einstein系数关系，非平衡泵浦建立反转，往返增益与相位自洽共同决定谐振腔中的振荡。

把反转、阈值和模式分别推清楚后，再用红宝石激光器理解泵浦、弛豫、储能与输出。自由电子激光使用周期磁场与相对论电子束：滑移条件确定共振，光与电子的能量交换推动微群聚，相干辐射随之增强。

## 从微观响应到介质传播

[第04章](optics-propagation.html)用受迫振子建立复极化率。复极化率决定复折射率，后者的实部控制相位、虚部控制衰减；响应随频率变化产生色散，随位置变化则引出光程和光线方程。

本章适合按“运动方程、响应函数、传播量、观测量”的顺序演算。这样可以从同一个模型求出折射率、透射率和色散，也能将Lorentz模型与电动力学中的Drude模型、趋肤效应联系起来。

## 全课程使用的记号

采用SI单位，实场由峰值复振幅表示：

$$
\mathbf E(\mathbf r,t)=\operatorname{Re}[\mathbf E_0e^{i(\mathbf k\cdot\mathbf r-\omega t)}],
\qquad \omega=2\pi\nu,\qquad \lambda_0=c/\nu.
$$

$\lambda_0$ 表示真空波长，透明介质中的相位波长为 $\lambda=\lambda_0/n$。$\varepsilon,\mu$ 是绝对参数，$\varepsilon_r,\mu_r$ 是相对参数。被动吸收介质采用 $\widetilde n=n_r+i\kappa$，$\kappa\ge0$；峰值复振幅的平均二次量含因子 $1/2$。谱密度中的 $\nu$ 按Hz定义，换用波长或角频率时同时变换谱密度。

## 推导与练习安排

| 学习节点 | 应能从头写出的推导 | 练习入口 |
| --- | --- | --- |
| 波动与场 | 行波到波动方程；Maxwell到横波与能流；复振幅到干涉项 | 第01章自测，原第二章作业 |
| 辐射 | 模式计数到Planck谱；谱积分与求峰；偶极远场到总功率 | 第02章自测、辐射量与谱变换练习 |
| 激光 | 热平衡到Einstein关系；衰减到线宽；往返条件到阈值与纵模 | 第03章自测、二能级与群聚练习 |
| 传播 | 振子到极化率；复波矢到吸收；远离共振的展开；Fermat变分 | 第04章自测 |

每完成一个节点，就选一道题，独立写出模型假设、起始方程和计算过程。[原作业索引与综合自检](optics-exercises.html)提供逐题定位，[电动力学联系](optics-electrodynamics.html)解释相同方程在两门课中的用途。

完成四个主题后，可转到[考试复习精简版](review-optics.html)检查概念和公式；较完整的查阅表见[公式总表](optics-formulas.html)。教材节号与课件页码见[来源索引](optics-sources.html)。
