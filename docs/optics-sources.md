### 教材核验后采用的表达

| 定位 | 核验与正文处理 |
| --- | --- |
| 第三章式(3.48)、(3.50)干涉项 | 交叉项保留有符号内积，可为负；积化和差的系数由 $2\cos a\cos b=\cos(a+b)+\cos(a-b)$ 确定，不能对交叉项取绝对值或重复乘2 |
| 第五章式(5.13)吸收率 | 原生分式与前后文字定义不一致；采用“吸收能量/入射能量”，满足被动样品 $0\le a_\lambda\le1$ |
| 第五章式(5.18a)、(5.19b)频率形式 | 原左侧仍沿用波长变量记号；正文区分 $M_\nu$ 与 $M_\lambda$，写清Jacobian |
| 第五章偶极场式(5.3)、(5.4) | 教材已有SI的 $\varepsilon_0$ 因子；先前PPT缺项的订正只针对PPT，不归因于教材 |
| 第六章532nm、300K热平衡布居算例 | 以完整常数得指数90.1489、布居比 $7.06\times10^{-40}$；若用舍入能量 $3.7\times10^{-19}\,\mathrm J$ 则约 $1.60\times10^{-39}$，均不能得到 $10^{-21}$ |
| 第六章纵模波长顺序 | 频率随模序号增大而增大，波长减小；用正间隔大小 $\lvert\Delta\lambda_0\rvert\simeq\lambda_0^2\Delta\nu/c$，不混淆有符号差值 |
| 第六章式(6.29)、(6.30)波荡器参数 | 本资料统一平面波荡器峰值定义，对应 $1+K^2/2$；$K=0.934B[\mathrm T]\lambda_u[\mathrm{cm}]$，周期用米时系数为93.4 |
| 第六章“阈值长度”“只限自然线宽”“均匀束不能放大”等表述 | 分别说明损耗及增益分布、实际增益带宽、连续均匀平均与有限粒子涨落/群聚；不作为无条件命题 |

教材第二章式(2.28)原式含绝对值，部分行波式原有括号；纯文本提取会丢失这些结构，未据提取结果把它们列为教材错误。以上订正采用原式核对和物理复算，并非仅凭另一轮模型回答。
