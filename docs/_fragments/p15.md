## P15｜报告必须让别人知道你做了什么、没做什么 {#p15}

[↗ 第三讲：验证结论的边界](lecture-3.html#c5)

<strong>目的：</strong>报告数据划分、预处理、结构、损失、优化器、随机种子、预算、选择规则、最终指标和限制。

```text
报告最小清单
1. 环境与随机种子
2. 数据划分与预处理
3. 模型结构和参数量
4. 损失、优化器、训练预算
5. 验证选择规则
6. 一次最终测试及诊断图
7. 未验证事项与下一步
```

<strong>通过：</strong>数值来自保存的 JSON 或日志。

<strong>常见错：</strong>把 quick run 写成完整实验。
