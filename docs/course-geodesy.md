# 大地测量课程总览

在测站 P 架设仪器，测得目标 Q 的方向与斜距，怎样得到可比较的位置？这门课沿着这个问题，连接参考面、椭球几何、测地线、观测归算和坐标转换。

第一次学习时先看图和完整例题，跟着正文建立概念；需要理解公式来历时展开详细推导。每个专题末尾有两至三道简短自测，解析默认收起。读完后应能解释符号与条件、完成相应计算，并用独立关系检查结果。

## 怎样读公式

先问图中固定的是点、轴还是参考面，再读相应的数学式。公式旁会写出角度单位、坐标顺序、旋转方向与近似条件；长推导可展开，核心结论和条件在正文可见。首次遇到术语时读本页解释，随后用[术语与公式索引](geodesy-glossary.html)回查。

本课程默认掌握基础微积分和线性代数。[数学准备](geodesy-math.html)补足参数化、偏导、切向量与度量。计算中的角度内部使用弧度，交互面板通常用度显示。椭球高统一记作 h；原讲义有时记 H，引用原题时注明。曲率半径 N、北向分量 N 和大地水准面差距 N_g 按各自定义区分。

先看子午面上的法线与地心向径，再看赤道面的经度投影；增加 h 时点沿同一法线移动。本站按正算模型绘制。

看图时先沿法线找到点 P 的脚点，再看 p、Z 怎样投影到 XYZ。进入第五章后可以改变经纬高，检查各坐标与读数的关系。其余图解依次解释三种纬度、曲率方向、测地线、观测归算与转换枢轴。

贯穿课程采用“模型—局部标尺—曲面路径—观测归算—坐标转换”的计算链。现有讲义原题保留原椭球设定；需要自选椭球的演示明确标注WGS84，不把不同椭球的结果拼接成同一算例。
