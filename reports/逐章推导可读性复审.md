# 逐章推导可读性复审

日期：2026-10-11。评审依据是仓库现有 Markdown 正文与对应公式，不以另一个网站的内容替换课程。范围为三讲 26 个知识点及实践 P0–P15 的阅读顺序、首次定义和关键计算连接。原教材、课件、代码流程与历史输出不改。

## 主要发现

上一轮降低了标题和大纲的密度，也补充了很多名词，但仍有一些“符号已经解释，推导动机没有解释”的段落。只加术语释义不能解决这个问题；应说明为什么改写目标、每个矩阵保存了什么、前后式子之间用了哪条规则，以及结果为什么满足原问题。

最明显的是 B3：读者先遇到散度、二次型、比值，随后直接看到逆矩阵结论；附加证明又同时使用商求导、乘子、平方根和不等式。对于第一次学 Fisher 的读者，这些并列方法增加了负担。

| B5 Logistic | 链式求导开始时单样本损失没有就地写清。 | 从平均损失取出 ell_n，明确标签固定、概率变化，再进入三因子求导。 |
| B6 Softmax | 最后两次求和约简对初学者仍可能跳步。 | 指出指示符只留下 k=j 的项、p_j 提出求和号，以及标签总和为 1。 |

Fisher 新主线：投影坐标 → 投影中心差 → 从标量偏差平方展开散度矩阵 → 比值为什么不受整体缩放影响 → 统一中心差为 1 → 最小化类内波动 → 解释约束面与拉格朗日乘子 → 二维逐坐标求导 → 线性方程 → 方向解与尺度。

正文明确正定与不同均值条件。“1”是尺度规范，不是数值算例。逆矩阵作为解线性方程的简写，解释为用类内波动调整均值差；相关特征需要联立求解。最优性用可行扰动的平方展开证明，不再需要矩阵平方根。该证明及生成 LDA、特殊标签最小二乘关系按需打开，必要边界条件留在正文。

## 实践

实践页的主要问题是读代码前缩写和维度缺少解释，运行流程不需要调整。本轮在 P1/P2 解释 RGB、CHW/HWC 和张量，在 P4 解释 batch 与 epoch，在 P5/P6 连接像素展开、3072 维输入、logits 与 MLP，在 P8 解释清梯度的原因，在 P9 区分 eval 与 inference_mode，在 P14 解释混淆矩阵。P0、P3、P7、P10–P13、P15 的配置、验证、训练预算与报告规则保持；对应代码由原脚本生成。

## 核验与继续评估

新增九项 Fisher 核验：投影均值差、投影散度、距离约束、最小散度、乘子目标有限差分/自动微分、可行扰动的全局差值、广义特征值最大比率、缩放不变性。另用三层光滑网络的自动微分独立核对 C2 前向 Jacobian 组合及反向转置。

本轮不将“增加解释文字”当成已经证明学生能无痛理解。后续读者反馈最有价值的问题是：能否自己从投影偏差写出散度矩阵，能否解释固定中心距离为什么不改变方向选择，能否从两条标量导数写出线性方程。机器核验检查数学、链接和页面功能；上述阅读判断来自正文复审。
