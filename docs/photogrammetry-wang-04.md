本章主线来自王佩军、徐亚明《摄影测量学》第四章，印刷 **p.54–70，PDF63–79**。原书四节分别是人眼的立体视觉、立体像对与测图原理、相对与绝对定向元素、立体测图概述。学习目标是把“我看见它有高度”转换成“哪两条射线给出了这个点，怎样建立坐标和尺度，最终怎样得到可检验的测量成果”。

双像测图利用两个不同摄站获取同一场景的重叠影像，恢复成像几何，重建地面模型，再量测或制图。立体观看可以帮助人寻找同名点，却不等于坐标已经求解正确。尤其要区别：**双眼看出的视模型、数学定义的几何模型、纳入地面基准的模型**。三者联系紧密，但不能用一种感觉替代其他两层的条件。

## 4-1 人眼的立体视觉原理与立体量测 {#s4-1}

来源：王书印刷 p.54–59，PDF63–68。原书从天然立体视觉，到人造立体视觉，再到分像方法和立体量测，依次说明人为什么能从两幅平面影像感觉空间深度。

### 天然立体视觉：左右眼确实看到不同方向

**天然立体视觉 / natural stereoscopic vision** 是双眼分别从两个位置观察同一对象，两幅视网膜影像中的对应关系帮助判断深度。眼睛的晶状体可以调焦，让不同距离的对象清晰成像；双眼视轴可以转向所注视对象，形成交会角。调焦与视轴交会是有关联的生理动作，但它们不是同一几何量。

设两眼中心距离为眼基线 $b_e$，对象位于两眼中点正前方、距离为 $L$，双眼视轴交会角为 $\gamma$，对称几何给出

$$\tan\frac\gamma2=\frac{b_e}{2L}.$$

若距离远大于眼基线，$\gamma$ 很小，以弧度表示时可近似 $\gamma\approx b_e/L$，所以 $L\approx b_e/\gamma$。远处对象的双眼角差更小，不是眼睛的基线突然变短，而是同样眼基线在更长距离上产生更小的方向差。眼基线在书中以约65毫米作平均示例，它随个人不同，不是要求每个人恰好相等。

**生理视差 / physiological disparity** 是对象在左右眼对应影像位置上的差异。王书用两个邻近点相对视网膜弧长的差来说明：距离不同，左右影像中点间距离也不同，双眼因此获得相对远近信息。它与第五章像平面量测的左右视差有相似几何结构，但单位、坐标原点与观察方式并不完全相同，不能把生理毫米差直接当成航空像片的像坐标差。

**原创英语：** *The two eyes observe the same object from different positions.* 核心结构是 two eyes / observe / the same object；from different positions 解释方向差从何而来，不是说左右眼观察两个不同物体。

### 为什么越远越难分辨细小深度差

由小角近似 $L\approx b_e/\gamma$ 微分，带符号变化有 $dL\approx-b_e\,d\gamma/\gamma^2$。若只关心可分辨深度差的大小，则

$$|dL|\approx\frac{L^2}{b_e}|d\gamma|.$$

王书式4-2还用眼焦距 $f_e$ 与视网膜视差变化 $\sigma$ 近似联系 $|d\gamma|\approx|\sigma|/f_e$。于是距离增加一倍，在角辨别能力相同的假设下，能够分辨的绝对深度差约增加四倍。这里所有角差必须使用弧度，眼基线、眼焦距和生理长度差必须按一致单位处理。

书中以50米距离、约30角秒辨别阈值估计可分辨深度差约5.6米。换算过程为 $30''\approx1.454\times10^{-4}$ 弧度，$50^2/0.065$ 米乘这个角差，得到约5.59米。这个数字是书中简化条件下的示例，不能当成对所有人、所有纹理、光照与视力状态的生理测试结果。它主要教你读出距离平方增长规律。

单眼也能利用遮挡、相对大小、阴影、透视和运动信息推断远近。因此“单眼不能感知任何深度”说得过头；更准确的是单眼静态影像缺少双眼视差这条直接线索，不能仅由一个像点严密恢复任意空间位置。摄影测量希望获得带尺度和坐标的几何量，比凭经验知道某物“可能较远”更严格。

### 人造立体视觉：让每只眼睛只接收一张照片

**人造立体视觉 / artificial stereoscopic vision** 用分别从两个位置拍得的像片，替代两眼原来看到的场景。左眼看左片、右眼看右片，影像内保留下来的视差可在视觉中重现深度。即使照片平放桌上，它们不是两个真实三维模型；你脑中融合出来的才是视模型。

王书列出四类基本条件。第一，两张照片必须来自不同摄影位置，且包含同一场景；仅复制一张照片不具有原始基线。第二，每只眼睛只看它对应的一张像，叫**分像 / image separation**。第三，对应景物在左右像上的连线方向应与眼基线大致匹配，使主要深度差表现为横向差，而不是无法舒适融合的上下错位。第四，两影像显示比例应接近，差得太大时需要变倍或重采样。

这四条件不能拆开各自孤立操作。你可能把两张影像大小调到一样，却仍然选错左右对应顺序；也可能把行对齐了，但对应对象被遮挡，左右眼就找不到可融合内容。书中比例尺差异约小于15%是传统观看条件的经验要求，现代可通过显示变换处理一部分差异，仍需要保持正确的对应几何。

### 正立体、反立体与高度感觉

**正立体效应 / normal stereoscopic effect** 指深度关系与实际相符。若把左右像片交换给左右眼，视差的相对符号会改变，凸起可能被感到凹下，形成**反立体效应 / pseudoscopic effect**。王书图4-4还说明特定像片旋转和摆放会引起这种效果。

这不是地面高程真的变负，也不是数据文件里坐标自动改变，而是眼睛接收的视差被重新解释。处理时应核对影像拍摄顺序、对应眼睛、行列轴方向与显示姿态，不能仅凭“我看到山谷像山峰”决定整个地面模型错在高程基准。

看到的立体模型高度有时显得夸张。摄影基高比、观看距离、显示比例与眼基线影响视觉的纵横比例；视觉夸张不等于数学计算把所有高程放大同一个倍率。只要量测系统按正确相机与显示几何求解，仍可得到真实尺度的坐标。相反，视觉很自然也不是测量精度的保证，基线过小的像对可能看着舒服却深度几何较弱。

**原创英语：** *Swapping the left and right views can reverse the perceived depth.* perceived depth 指感知深度。句中的 can 表明这是显示与观察条件下的效果，不能机械扩大为任何图像交换都必然得到可计算的反号高程。

### 五种分像方法：共同目的，技术方式不同

**立体镜观察 / stereoscope viewing** 利用透镜或反射镜把左右像分别导向左右眼。小型桥式立体镜适合较小像幅；反射立体镜能让较大像幅保持分离，仍便于观察。透镜常将光线整理成便于眼睛放松观看的方向。学习时不必记住每个镜片的品牌，要看左右光路是否真的分开。

**双目观测光路 / binocular optical paths** 用两套物镜、目镜和其他光学元件连接左右影像和左右眼，在模拟、解析测图仪中常见。其优势是光路和量测机构能协调，观察者可以随量测位置移动查看同名点。光路里两个测标的位置可以单独调节，形成后面讲的浮游测标。

**互补色法 / anaglyph viewing** 对左右像分别使用不同颜色，并用对应滤光眼镜分离。它用波长/颜色实现分像，而不是用左右位置本身实现分像。若颜色过滤不充分，眼睛会接收到另一张像的部分内容，形成串扰；原图颜色也可能受影响。它适合演示视差和深度，不应仅凭有彩色立体效果就认为适合所有精密任务。

**同步闪闭法 / synchronized shutter viewing** 交替显示左右帧，同时同步开关左右眼镜，使每只眼睛在相应时刻看到对应影像。书中介绍的显示频率属于其设备背景。真正要理解的是时间同步：若显示帧与眼镜开关不同步，左右视图会串扰甚至反转。帧率、亮度、延迟等工程因素影响体验，但不会改变摄影时两摄站的几何基线。

**偏振光法 / polarized viewing** 让左右像携带不同偏振方向，由眼镜分别透过。投影时还需屏幕保持偏振特性；某些数字显示使用偏振切换或固定分配方式。它以光的偏振性质实现分像，不同于按颜色过滤。观察头部姿态、屏幕和眼镜的实际组合会影响分离效果，书中工作站说明应作为原理和历史设备背景阅读。

这些方式共同解决“左右眼各看一张”的问题。它们本身不负责恢复未知外方位，不负责估计地面尺度，也不负责辨认任何两个相似纹理是否来自同一物点。将显示层和几何求解层分开，能避免把一个看不到立体的显示问题误判成共线方程失效。

### 浮游测标：用左右像面二维移动控制三维位置

**浮游测标 / floating mark** 是左右光路中一对测量标记融合而成的空间测标。标记可以像小点、短线或十字，它们的位置可被操作。观察者让这个测标与立体表面“切准”，便记录该位置。它是一个可量测工具的可视表现，不是影像里自然存在的地物。

王书图4-8在左右照片上分别画 $m_1,m_2$，通过各自光路形成两条测标视线；当它们对应到同一个地面对象时，融合测标落在表面 $M$。相对水平移动两个测标，改变它们的视差，使融合测标升高或降低；协调移动两个测标，改变横向位置。二维像面上的两个控制点因而能操纵一个三维标记。

“切准”不是只让左测标落在明显角点。左标切准、右标却错，可能仍产生一个看似稳定的空间标记，但对应的是错误射线。正确量测需要两标分别切准同名点，并处理上下错位和显示/定向误差。模糊纹理、反光屋面和重复窗格会让人也产生错误匹配，人工测量不能豁免对应关系检验。

判断浮游测标的高度，可以想像你在平面上移动一个物点的左右影像：较近的点在两幅图中差得较大，较远的点差得较小。但标的实际高度应由采用的像坐标、基线、相机姿态和模型坐标系统计算，不能根据观察者觉得“浮起了两厘米”就当成实际楼高两厘米。

精度还和标记形状与纹理有关。王书用点状、线状标记辨别能力的示例说明：细线的对准有时比孤立点更易精细判断。不过完整系统精度还受相机几何、像质、放大倍率、匹配与定向条件影响。把眼睛局部判别阈值直接写成物方高程精度，缺少从像面到物方的误差传播。

## 4-2 立体像对与立体测图原理 {#s4-2}

来源：王书印刷 p.60–63，PDF69–72。本节从像对特殊点、线、面，说明摄影过程的几何反转，再解释恢复顺序和上下视差。

### 像对的特殊点线面建立在两个摄影中心上

**立体像对 / stereo pair** 是两个不同摄站获取、对同一场景具有共同影像的一对照片。设左、右摄影中心为 $S_1,S_2$，它们的连线为基线 $\mathbf B=S_2-S_1$。同一物点 $A$ 的左右像为 $a_1,a_2$，称**同名像点 / conjugate image points**；$S_1a_1$ 与 $S_2a_2$ 称同名射线。相似纹理点不必来自同一物点，同名要求的是实际对应，不是图案看起来相像。

<SourceFigure src="/photogrammetry/wang/ch4-epipolar.png" alt="王书图4-9局部：基线、同名射线和核面核线" source="王佩军、徐亚明《摄影测量学》局部图" page="69" printed="60" note="先按正文读图，再点击放大辨认点线面与符号。" />

**读图第一步：** 找 $S_1,S_2$ 及它们之间的 $B$，随后只选一个物点 $A$。基线与这个物点确定一个平面 $W_A$，即**核面 / epipolar plane**。物点的两条同名射线都在这个平面内，这是一般成像几何必须满足的关系。

**第二步：** 看核面穿过左、右像片的交线，这两条是**同名核线 / corresponding epipolar lines**。左像点必须落在左核线，右像点必须落在同一核面的右核线。已知两相机几何后，给定左像点可确定相关核面，于是在右像上找对应点时能把二维搜索限制到相应核线附近。核线给候选位置，不会凭空认出线上哪一个纹理是真的对应。

**第三步：** 延长基线与左右像面的交点 $k_1,k_2$，它们是**核点 / epipoles**。凡含同一基线的核面，其像面交线都通过相应核点，因此一幅原始照片中的核线通常形成线束，不天然全是水平线。若基线与某个像面平行，核点可位于无穷远；经适当核线重采样后，核线常可对齐成平行行。这是校正后的便利，不能倒推原始照片一开始就具有同样行结构。

王书还定义经过像主点的核面为**主核面 / principal epipolar plane**。左右主点一般不位于同一个核面，因此左主核面和右主核面不一定重合；这和单像的主垂面又是不同定义。经过像底点的核面称**基核面 / nadir epipolar plane**，因为基线和两个摄站的铅垂方向可以处在同一垂直平面内，一对像片有共同基核面。读图时问“这个面通过哪几个已知几何对象”，可帮助你分清名称。

**原创英语：** *The baseline and one object point define an epipolar plane.* object point 只有一个；核面同时贯穿两幅像片，不是左像与右像各有互不相关的一张面。

### 用向量表达三线共面，避免仅凭图感判断

使用第三章王书约定，在同一个辅助/模型坐标系统下，两张照片的理想像点方向为

$$\mathbf r_1=R_1(x_{1c},y_{1c},-f_1)^T,\qquad
\mathbf r_2=R_2(x_{2c},y_{2c},-f_2)^T.$$

$R_i$ 从各自相机空间变到共同辅助空间，不能让 $\mathbf B$ 用地面轴、$\mathbf r_i$ 仍用各自相机轴后直接作叉积。共面条件为

$$\mathbf B\cdot(\mathbf r_1\times\mathbf r_2)=0.$$

叉积给出两方向张成平面的法向，点积为零表示基线也在该平面内。方向向量放大或缩小不影响“是否为零”，因此单靠这个条件没有确定绝对基线长度。对一般非退化、方向有效的同名射线，恢复共面后可以交会成模型点；平行射线、错误对应或退化几何仍需要额外判断，所以不能把“满足一个共面数值”当成全部成功条件。

第五章将利用这个条件求解析相对定向。本章先掌握它的物理对象：基线、左射线、右射线三者在同一个平面。不必在这里提前背整页偏导，否则很容易在转到第五章时丢掉哪些量是未知的。

### 视差与高度：先声明理想像对

为了把高度关系看清，采用一个特殊但可严格推导的像对：两相机等高，像面等效表示平行，内方位已知且主距相同，基线沿共同 $X$ 轴，横向轴约定与第三章 $z=-f$ 模型一致。左摄站 $(0,0,H)$，右摄站 $(B,0,H)$，物点为 $(X,Y,h)$。$H$ 是相机相对选定高程基准的高度，$h$ 是物点相对该基准的高程，$H-h>0$。

以各自主点为原点的像坐标由共线方程得到

$$x_L=\frac{fX}{H-h},\qquad x_R=\frac{f(X-B)}{H-h},\qquad
y_L=y_R=\frac{fY}{H-h}.$$

明确将左右视差定义为 $p=x_L-x_R$，则

$$p=\frac{fB}{H-h},\qquad h=H-\frac{fB}{p}.$$

这里的正视差来自已经声明的轴与差值顺序，绝不意味着任何真实负片坐标都可以不变地用这个符号。若你改成右减左，或把真实负片反向坐标直接使用，$p$ 符号会改变，应由新的成像关系重新推导。将“正视差”与 $z=-f$ 混用而不声明像面和轴，就是许多背公式错误的来源。

在这一理想模型中，物点越高，离相机越近，分母越小，视差越大。例如 $f=0.1$ 米、$B=100$ 米、$H=1000$ 米，基准面点视差10毫米；高程100米点视差约11.111毫米。实际影像可以有不同旋转、航高、主距和像面坐标原点，不应直接把任意两图里“两个横坐标差”代入这个特殊公式。

两个物点的高程差严格满足

$$h_t-h_b=fB\left(\frac1{p_b}-\frac1{p_t}\right)
=(H-h_b)\frac{p_t-p_b}{p_t}.$$

只有高差/视差差相对较小时，才可以用 $p_t\approx p_b$ 得到线性近似。纸面复习题常写 $\Delta h\approx H\Delta p/b$，其中 $b$ 必须是对应参考平面的像片基线/视差且基准高度定义一致。把摄站基线 $B$ 与像片基线 $b$ 用同一单位却不区分物像空间，会使结果差一个尺度倍数。

**原创英语：** *With fixed camera geometry, a higher point has a larger disparity in this ideal stereo model.* 最后的限定 this ideal stereo model 必须保留；不是说任何两幅未校正影像的横坐标差都能直接按这个规则排序高程。

### 摄影过程的几何反转

在真实摄影中，地面光线分别进入左右相机，形成两束记录在像片上的射线。若在测图仪上用已知主距和主点恢复这两束光线，再恢复它们之间的相对关系，同名射线就能相交，交点集合组成与实地相似的模型。书中称为**摄影过程的几何反转 / geometric reconstruction of the imaging process**。

<SourceFigure src="/photogrammetry/wang/ch4-reconstruction.png" alt="王书图4-10局部：成像与恢复模型" source="王佩军、徐亚明《摄影测量学》局部图" page="70" printed="61" note="先按正文读图，再点击放大辨认点线面与符号。" />

**读图方法：** 左侧先找摄影时的摄站基线 $B$ 和地面 $A,M,C,D$，再看恢复时较小的基线 $b$ 与模型 $A',M',C',D'$。对应射线方向保持时，基线从 $B$ 缩到 $b$，模型也按同一比例缩小；模型与地面长度比为 $b/B$。右侧的测绘台上下移动，使测标切准模型表面；平面移动让笔沿对应位置绘出线划。

投影器在这里是说明原理的装置，并不要求现代计算机真的发出两束可见光。数字系统用射线方程和共线模型代替光路重放，只要几何与观测处理正确，恢复的数学对象相同。物理装置与数学方法变了，内外方位的重要性并没有消失。

### 恢复顺序：内定向、相对定向、绝对定向

**内定向** 恢复单片内部光束：让量测坐标、主距、主点和所用改正关系符合摄影模型。扫描胶片要用框标建立扫描像素与像平面坐标的变换；直接数字相机可以省去胶片框标测量，但仍必须知道像元尺度、主点和相机模型，不能说数字相机无须任何内方位信息。

**相对定向 / relative orientation** 恢复两片之间的几何关系，使同名射线符合共面/交会条件，建立一个自由尺度与任意整体姿态的模型。**绝对定向 / absolute orientation** 再用地面控制等信息赋予这个模型真实尺度、位置和方向，纳入地面坐标系统。内定向解决每张片自身；相对定向解决两束之间；绝对定向解决整个模型和地面之间。

这三步是原书第四章的理解主线。第五章还会给两片分别后方交会再前方交会的另一条求解路线，以及同时估计相机与物点的光束法。路线不同不代表额外一套成像物理，而是不同的未知量组织与计算步骤。

### 上下视差为什么不能靠升降测绘台消掉

王书图4-11定义**上下视差 $Q$ / vertical parallax**：当两同名射线没有恢复正确相对关系时，它们可能在空间错开；升降承影面消去某一横向差以后，仍留下 $Y$ 方向的分离。对正确恢复且无观测误差的像对，相应射线应该能够在模型点交会，理想上下视差为零。

若两条射线一般不共面，它们是异面直线。把测绘台升高或降低，只是改变这些射线与一个水平面的交点，并不能让异面线在空间突然相交。因此反复调高程让一处看着融合，不等于相对定向已经正确。必须调整相对位置或姿态，使一批分布良好的同名点共同满足关系。

上下视差与左右视差有不同角色：上下差通常是定向/对应或观测问题的信号；左右差则承载深度，不应一概消成零。完成相对定向后，在某个承影面上的左右交点仍可分开，升降承影面到相应模型高程便会相合，这正是量测深度的机制。

实际含噪条件下不要求每个点严格零差。需要采用误差容许、整体残差和独立检查点来评价。某一个点的 $Q=0$ 只能说明那里满足了某种局部条件，不能证明全片所有点都正确；错误同名点也可能恰好落在核线上，因此还需结合影像相似性和多点几何检验。

## 4-3 相对定向元素与绝对定向元素 {#s4-3}

来源：王书印刷 p.63–65，PDF72–74。这里最容易误记的是“五个相对元素”和“七个绝对元素”。它们来源于坐标选择和自由度，不是因为一种算法恰好喜欢五或七。

### 为什么两片十二个外方位只剩五个相对自由度

已知两片内方位时，每片有六个外方位，共十二个。若我们只关心像对内部关系，整个相机与模型一起平移三项、旋转三项、统一缩放一项，都不会改变影像里的内部投影关系。这七个整体相似变换自由度在相对定向阶段不由像对本身确定。因此一般非退化、已检校的双像内部关系有 $12-7=5$ 个独立自由度。

“有五个元素”不等于任意五个像点必定唯一求解。每个真实同名点提供一个独立共面条件的思路是最低计数，但点位退化、噪声和多解都可能存在。原书模拟作业常以五点调整，再用第六点检查；现代解析/数字作业应取更多且分布合理的对应点，形成冗余和检核。

从几何看，把已经建立的模型、两摄站和全部射线一起搬动，它内部一点也没有改变。相对定向不应被迫选择国家坐标或真实尺度；它可以按方便计算的基准先建立模型，后面再连接控制信息。正因为这个整体任意性，不同相对定向系统可以有不同参数而描述同一个像对。

### 连续像对：固定左片，求右片相对关系

王书的**连续像对系统 / consecutive-pair orientation system** 以左摄站为原点，左片像空间坐标系作为像对辅助坐标系统。左摄站的三个位置和三个角在这个系统里都是零，这是选择坐标基准，不是断言真实左相机水平、没有转角。

右摄站位置为 $(b_u,b_v,b_w)$，右片角为 $\varphi_2,\omega_2,\kappa_2$。其中沿主方向的基线分量 $b_u$ 决定模型尺度，可以先指定。剩余五个相对元素为

$$b_v,\ b_w,\ \varphi_2,\ \omega_2,\ \kappa_2.$$

有些解析实现把基线分量改成无量纲比值 $b_v/b_u,b_w/b_u$，书上位置元素则可能使用模型长度。二者思路相同，但求导、单位和更新量不同，不能把以弧度计算的基线倾角直接当成米级 $b_v$ 加到位置中。

连续系统适合把一条航线中的像对接着处理，左片作为已建立关系的参考，再恢复右片相对关系。它不是说摄影时飞机完全不动，也不是把右片全部位置固定。左片“固定”是本像对的坐标/计算选择。

### 单独像对：把基线放在一条轴上

**单独像对系统 / independent-pair orientation system** 仍以左摄站为原点，但把基线选为 $U$ 轴；选择左主核面作为适当参考面，使左片一个角 $\omega_1=0$。左右摄站为 $(0,0,0)$ 与 $(b,0,0)$，基线长度 $b$ 只控制统一尺度，先给定。

此时五个相对角元素为

$$\varphi_1,\ \kappa_1,\ \varphi_2,\ \omega_2,\ \kappa_2.$$

连续像对的左片三个角都固定为零，单独像对则主要固定基线与左主核面方向，所以左片仍有两个角待求。不要把两系统的五项拼成一个新的“通用五参数”：必须先按各系统把基准约束写全。

<SourceFigure src="/photogrammetry/wang/ch4-relative.png" alt="王书图4-13局部：连续与单独像对的坐标选择" source="王佩军、徐亚明《摄影测量学》局部图" page="73" printed="64" note="先按正文读图，再点击放大辨认点线面与符号。" />

**读图方法：** 左半图先看基线在 $U_1$ 方向以外还具有 $b_v,b_w$，右片三个角也待恢复；右半图把两摄站放在同一 $U$ 轴上，左主核面成为参考面，因此基线分量消去而左片两个角出现。两个图中参数外观不同，但都是恢复同名射线关系，不能用“左相机画得更斜”判断哪一个正确。

可以用同一实际像对做思考实验：先用左相机轴描述它，记录右相机的横向和竖向位移；再整体旋转坐标系，让基线成为 $U$ 轴。新坐标里那两个位移分量为零，姿态角则相应变化。物理相机和射线没有改变，改变的是描述方式。这个实验把第三章“同一点换坐标”推广到第四章“同一像对换基准”。

**原创英语：** *Different orientation systems describe the same stereo geometry with different parameters.* same stereo geometry 提醒内部关系相同，different parameters 提醒不能强求不同转序或基准下的数值角一模一样。

### 绝对定向：七个参数把自由模型接到地面

相对定向后模型有三维形状，却仍不知道用哪个真实尺度、放在哪里和朝哪个方向。**绝对定向** 采用三维相似变换，令模型点 $\mathbf P_m=(U,V,W)^T$，地面摄影测量坐标 $\mathbf P_g=(X,Y,Z)^T$：

$$\mathbf P_g=\lambda R_g\mathbf P_m+\mathbf t.$$

$\lambda$ 是统一尺度，单位为“地面长度/模型长度”；只有两侧使用相同长度单位时才无量纲；$R_g$ 是模型→地面的纯旋转矩阵；$\mathbf t=(t_X,t_Y,t_Z)^T$ 是三个平移，单位同地面坐标。角参数有三个，加尺度和平移，共七项。这里 $R_g$ 是这次模型到地面变换，不是第三章相机射线的 $R_i$；下标区分不同输入输出空间。

统一尺度保留所有角度和形状，只把长度按同一比例变化。它不允许 $X$ 放大两倍、$Y$ 不变、$Z$ 再放大三倍，那样已经是非相似形变，不能解释为普通绝对定向。若模型存在弯曲或局部形变，仅用这七项可能无法消除，需要回到影像定向、连接点和误差模型检查。

地面控制点提供模型与实地的对应坐标，才使七参数可求。学习三维相似变换最清楚的示例是三个不共线、在两系统中都有完整三维坐标的点；还要考虑非退化布设与噪声下的冗余。王书第五章细化到平高与高程控制的组合，本章先建立“控制的坐标维度和几何分布都重要”的认识，不以总点数代替全部条件。

三个点如果挤在很小区域或几乎共线，对某些姿态的约束很弱；控制点平面范围太窄，模型边缘的外推误差可能很大。点数看似多也不能保证结果可靠。控制点用于定向，检查点应尽可能独立于求解，用来评价结果，不能同一批点既无条件当作拟合输入又宣称全部是独立精度验证。

### 一个小模型如何恢复尺度和位置

设模型中的一段长度为20个模型单位，对应地面长度100米，那么尺度应为每模型单位5米。若模型单位已按米表达，可以把 $\lambda=5$ 理解为无量纲长度比。随后利用多个方向的控制信息求模型轴相对地面轴的旋转，再求平移，使一个或多个对应点落到实际坐标。

例：模型点 $(2,3,4)$，统一尺度2，绕地面 $Z$ 轴正向旋转90度采用 $R_g=\left[\begin{smallmatrix}0&-1&0\\1&0&0\\0&0&1\end{smallmatrix}\right]$，平移 $(100,200,10)$ 米。旋转后为 $(-3,2,4)$，乘尺度后为 $(-6,4,8)$，地面坐标为 $(94,204,18)$ 米。平移在尺度和旋转之后加，不要把 $\mathbf t$ 也再乘一次尺度。

此例的角约定已经明确，并非要求所有软件90度必须用同一个矩阵。若按王书另一个角系统表达，也可得到相同的最终旋转映射。求解和变换完成后，还应核实控制点残差、检查点误差和模型尺度，不能只看三维窗口里模型“摆得正”就结束。

**原创英语：** *Absolute orientation gives the model a scale and a place in the ground reference frame.* absolute 在这里指连接到外部基准，不是“绝对没有误差”。

## 4-4 立体测图概述：仪器改变，几何任务延续 {#s4-4}

来源：王书印刷 p.65–70，PDF74–79。原书依次讲模拟法、解析法和影像数字化立体测图。这些设备介绍应作为摄影测量发展历史及原理载体，不能把A10、B8S、C-100、BC-2等旧仪器型号当成当代学习者必须采购的设备清单。

### 模拟法：把成像关系装进光学与机械结构

**模拟立体测图 / analog stereoplotting** 用光学或机械投影恢复射线与模型。机械导杆可代表同名光线，像片盘和投影装置能按姿态、基线分量移动，手轮、脚盘或测绘台用来控制模型中位置。原书图4-15、图4-16的仪器照片与结构图，目的在于让你看见哪些机械自由度对应哪些几何参数。

模拟内定向通过安装主距、把像片主点与像片盘对应点对齐等，恢复单片光束。模拟相对定向通过调整小螺旋，消除分布在共同区域中的上下视差，使同名光线交会。它未必显式输出五个参数的数字，但装置已经在几何上实现了相应变换，因此书中说“相当于”解出相对元素。

原书标准定向点位分布图4-17把点安排在两个主点附近与上、下方位置。为什么不用五个都挤在中心的点？因为不同转角与基线分量对不同位置的视差影响不同，需要空间分布帮助分离参数。第六点用于检核，增加一种未直接用于调整的条件。记点位图时应同时讲出这个原因，否则点号背得熟也不会判断其他数据的布设。

模拟绝对定向通过图底与模型对应控制点配准，先处理平面平移、平面旋转与一个高程起始值，再调尺度与整体纵横置平。调投影器基线长度改变模型尺度，调公共转角让模型倾斜匹配地面，高程控制约束置平。这个过程把七参数拆成几种可操作的机械动作，理解后便能看懂数学形式的相似变换。

当把测绘台高度固定在某个高程，观察者让浮游测标始终沿模型表面移动，笔画出对应等高线。**等高线 / contour line** 是模型表面与固定高程水平面的交线，不是影像上一条亮度相同的线。换一个高程，再追踪一次，就得到另一条等高线。遇到断崖、建筑和遮挡，要辨识地物与地形，不能在任何纹理边缘上都继续画等高线。

模拟装置受到机构行程、光学模型和操作方式限制，对部分系统影响不如数字计算灵活。其量测依赖人工识别与操作，制图主要产生线划成果。这里的历史知识重要在于理解摄影测量曾怎样把方程实体化，而不是要求你重复维护一套精密机械后才配学习现代几何。

### 解析法：计算机求理论像点，伺服让人看到它

**解析立体测图 / analytical stereoplotting** 利用数学方程取代复杂的机械/光学投影关系，但可能仍量测实体像片。原书将精密立体坐标量测仪、计算机、数控绘图桌、接口和伺服系统组成整体。编码器把机械位移转成数字输入，伺服装置把计算得到的控制量转成仪器运动。

理解它的工作原理可从一个目标模型点 $(X,Y,Z)$ 开始。已知定向后，计算机把该点通过左右共线方程正投影，求理论像点 $(x_1,y_1,x_2,y_2)$；再考虑相机、影像和仪器改正，驱动左右像片盘到相应位置。观察者通过双目光路看到测标与立体影像的关系，并继续操作位置控制。

所以这个系统不是计算机自动从任意照片里直接创造地面。它必须先内定向，测量足够的相对、绝对定向信息并求解参数，才可以让模型点和像点保持一致。当观察者移动模型坐标，计算机实时更新左右像点位置，伺服让测标和影像相应移动。计算、显示和机械联动的一致性，保证操作感觉连续。

原书提到实时运算与像片盘控制周期，属于当时仪器工程的背景。概念上的重点是“模型移动→共线正投影→左右像点显示/机械移动”，而不是你必须在现代网页里复刻某一个旧频率。现代系统可以直接用屏幕坐标显示，而不用驱动实体片盘，依然需要及时更新对应关系。

解析仪器可以在计算中处理多种系统改正，摄影参数适应性与数学表达较灵活。但**解析**描述的是几何计算方式，**数字影像**描述的是原始影像表示方式；两词不等价。仪器使用电脑并不表示输入一定是数字相机影像。它也可能处理胶片影像，人工通过光学系统辨认和量测。

**原创英语：** *An analytical plotter computes the image positions that correspond to a chosen model point.* chosen model point 是先指定的模型点，computes image positions 是从物方到像方的正投影。阅读时先识别计算方向，才不会把每次伺服操作误解为求未知三维点。

### 数字法：像元数据进入几何与匹配流程

**数字立体测图 / digital stereoplotting** 以数字影像或扫描数字化影像为输入，在计算机中进行定向、匹配、量测和成果生产。扫描胶片需先解决扫描坐标与像平面坐标转换；直接数字影像则按传感器与相机模型建立这条联系。两种输入都不能省掉内参及坐标定义，只是有时不再需要人工量测胶片框标。

影像相关与特征匹配可以替代一部分人眼同名点识别，使大量对应点和高程点可自动获得。这里的自动化仍需要几何约束、质量检验与困难区域处理。没有纹理的水面、重复窗格、阴影、植被移动和遮挡都会影响匹配；算法输出的点多，不能仅以数量认定结果正确。

数字系统的典型链条可分为：读取影像与相机信息；建立像面坐标关系；寻找并检查同名点；恢复相对/绝对或联合定向；交会计算三维点；组织高程表面或地物；生产并检验成果。第五章讲求解，第七、八、九章将进一步讲地面模型、匹配与正射影像。因此第四章的概述不是以后所有算法的替代品，它给你位置地图，让你知道每个后续方法承担哪一步。

数字产品包括**数字线划图 DLG / digital line graphic**、**数字高程模型 DEM / digital elevation model**、**数字正射影像图 DOM / digital orthophoto map**及其他栅格或三维产品。线划表达地物的矢量几何与语义；高程模型表达表面或地形高程；正射影像处理中心投影和地形导致的几何差异。把DEM渲染成灰度图，不会使它变成普通无高程属性的照片；把DOM存为图片，也仍需要其坐标参考信息才能正确定位。

### 人还在流程中的什么位置

原书数字化部分强调机器视觉与人工交互并存。理解这一点可以避开两个极端：一是觉得现代软件自动按钮能消除所有数据问题，二是觉得没有人的双眼立体观察便不可能测量三维。数学几何与自动对应可以产生三维结果，人工有助于核实复杂对象、边界和语义，也负责判断误差与项目要求。

若要测房屋轮廓，系统可能先自动生成稠密点云，再由人选择地物类型、确认屋檐与墙脚关系；若要生产裸地DEM，需要从树冠、建筑等表面点中识别地面。几何求出的是某个可见表面的三维位置，它不会自动告诉你这个表面应归入哪一类成果。产品定义会影响选择和后处理。

因此记录来源、相机模型、控制基准、匹配可靠性和检查点误差，是测图的一部分。图面漂亮、点云密集、立体效果强烈都只能说明某些展示特征，不能独自回答真实位置精度与成果适用性。

## 完整练习：从同名点到有尺度的地形 {#worked-route}

设有两张重叠数字影像，能看到道路角点、建筑与山坡。第一步不是先量所有高程，而是确认左右拍摄顺序、相机内方位、图像像元与主点坐标定义。第二步选择同名点，分散在共同区域，避开明显遮挡与移动物体。第三步建立两射线共面条件，求相对定向并检查剩余上下差；此时得到的模型可能仍是任意尺度。

第四步用地面控制把模型纳入实际坐标和尺度。第五步用定向后的多条射线计算待测对象坐标，保留匹配与交会质量信息。第六步按产品需求选择地面或地物表面，并用独立检查点评价。可以人工借助浮游测标完成部分步骤，也可以自动匹配并结合人工检核。步骤之间有不同输入与输出，不要将“有一个模型文件”视为全部结束。

假设一处楼顶在左像能看到，右像被另一栋楼遮挡，你不能在右像上找一个相似屋顶强行当作同名点。核线约束只能缩小候选区域，不能创造不可见内容。正确做法是寻找其他可见像片、使用多像信息，或把该点标为暂不可可靠量测。这个例子说明有几何公式不代表每个像素都有可求的深度。

再假设全部控制点都布在一侧。控制点拟合残差可能很小，另一侧却有较大位置偏差；相似变换无法凭空提供缺失区域的稳定信息。应检查影像网络、控制空间分布和独立点，而不是不断缩小显示比例让误差在屏幕上不明显。处理速度和显示效果不是精度检核方法。

## 章末问题与排错练习 {#checks}

1. 双眼分辨深度与相机从双像求三维有哪些共同几何？又有哪些生理和坐标上的区别？
2. 同一照片复制两份，分别给两眼观看，能否恢复原来的未知深度？
3. 为什么原始影像核线不天然水平？核点位于何处，由什么决定？
4. 相对定向主要消除哪一种视差？为何不能把左右视差全部消成零？
5. 连续与单独像对系统分别固定什么？五个元素分别是什么？
6. 绝对定向的七个参数为什么只含一个尺度？用三个独立轴向拉伸会改变什么？
7. 数字相机不量胶片框标，是否表示无须相机内方位？
8. 解析测图仪已经有计算机，为什么仍与数字影像测图不同？
9. 一批对应点都落在核线上，但结果仍错，有哪些可能原因？

<details><summary>对照解释：先说出几何对象，再看答案</summary>

双眼和双像都利用不同位置的方向差，但生理视差、显示过程和严密像坐标不是同一量。复制照片没有新增原始观测基线，不能补出任意真实深度。核线是核面与像面的交线，核点是基线与像面的交点或无穷远方向；是否水平取决于像面几何和后续校正。相对定向使同名射线符合核几何，理想上下差消除，而左右差承担深度。连续系统以左片为基准，求两个基线侧分量与右片三角；单独系统基线为轴、左主核面固定，求左片两角和右片三角。绝对定向使用统一尺度保持形状。数字相机仍需像元、主点和镜头模型，只可能省去框标量测。解析仪器可以在电脑控制下仍量实体像片；数字法直接处理像元影像。落在核线上只是几何候选，重复纹理、错误匹配、遮挡、退化网形、错误尺度或基准都可能造成结果问题。

</details>

排错可按层分开：如果每只眼都看到左右两像，先查分像和显示同步；若同名点在许多位置有上下差，查相对姿态、像面坐标和匹配；若形状内部一致但整体比例或位置错误，查绝对尺度与地面基准；若部分区域形状弯曲或局部偏差，查局部匹配、控制分布与定向模型。分层只是诊断起点，最后应由数据、残差和独立检验确认。
