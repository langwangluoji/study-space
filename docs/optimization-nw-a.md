# 附录A · 数学与数值基础

**Background Material**

这个附录是正文的工具箱。遇到不熟悉的符号或数值条件时，再回到对应部分；不需要在开始读第1章之前全部学完。原书先讲线性代数，再讲分析、几何与拓扑，两部分分别支撑“怎样计算”和“什么时候可以推出结论”。

## A.1 线性代数：先看对象与维度

矩阵 $A\in\mathbb R^{m\times n}$ 将 $n$ 维参数映成 $m$ 维结果。梯度是参数空间的向量；残差和参数不一定同维，Jacobian的行对应残差、列对应变量。转置在 $J^Tr$ 中把结果空间的信息映回参数空间。

内积 $x^Ty$ 衡量方向关系，范数 $\|x\|$ 衡量大小。欧氏向量范数与诱导矩阵范数有相应不等式，不能把逐元素最大值直接当成同一种矩阵算子范数。子空间的维数、秩、零空间与正交补解释了可行自由度和不可辨识方向。

对称矩阵的特征值解释曲率。$H\succeq0$ 表示所有方向二次型非负，不是所有元素非负；$H\succ0$ 则排除非零平坦方向。SVD适用于一般矩阵，奇异值说明某些输入方向怎样被缩放；很小的奇异值意味着数据变化或舍入可能在参数中被放大。

### 分解是计算公式的实际实现

Cholesky用于正定对称系统，LU及QR服务一般线性系统与最小二乘。对称不定KKT系统需要适当主元策略的分解；不能因它对称就直接使用正定算法。$LDL^T$中的2×2块也要作为块处理，而不是只看对角元素来判断惯性。

Sherman–Morrison–Woodbury描述低秩更新后逆算子的关系，但各被求逆部分必须可逆。它帮助理解拟牛顿和紧凑表达，不是鼓励在程序里显式形成每个逆矩阵。优先考虑需要的是解、乘积还是完整矩阵，再选择分解与存储。

### 舍入、稳定与条件数不是同一件事

conditioning是原问题对数据扰动的敏感程度；stability是算法实际结果能否解释成邻近问题的准确解。问题病态时，一个稳定算法仍可能输出对原始数据不够精确的参数；这不能简单归咎于算法。满列秩最小二乘的正规方程将2-范数条件数平方，QR/SVD常更适合数值计算。

报告残差可以检查算出来的点是否满足方程，但小残差不保证小参数误差：两者还受条件数联系。导航中的不可观测与接近不可观测，也不能仅由线性求解器返回success判断。

### 速率看误差比，残差还要结合条件数 {#rates-worked}

若误差依次为 $.1,.01,.001$，每次比值.1，是线性收敛。若依次为 $.1,.01,.0001$，符合 $e_{k+1}=e_k^2$，后一次/前一次的比趋零，是二次（因而超线性）机制。仅从“最后几步变快”不能反推所有定理条件已满足。

另取 $A=\operatorname{diag}(1,10^{-8})$。近似解在第二坐标误差1，只产生 $10^{-8}$ 的方程残差；小残差并不保证小参数误差，弱方向被条件数放大。正规方程 $A^TA$ 的二范数条件数会从 $10^8$ 变成 $10^{16}$，也解释为什么正文反复建议QR/SVD。

本附录适合按疑问跳查：算法里“渐近速度”不等于运行时间，方程里“算得很准”不等于参数可观测。量级、拓扑与隐函数等工具保留下面的定义，不将它们当成开始正文前的考试。


序列趋近一个点，与目标值趋近一个数，是不同收敛对象。线性速率常写 $\|e_{k+1}\|\le c\|e_k\|$，$c<1$；超线性要求相应误差比趋零；二次常写 $\|e_{k+1}\|\le C\|e_k\|^2$。这些名称描述渐近误差规律，不直接等于实际运行时间。

有限维中紧集是闭且有界；连续函数在非空紧集上达到极值。闭但无界不能单独保证最优存在，严格凸也只保证若存在则唯一。定义域的开闭和函数是否趋于边界或无穷远，都是正文存在性讨论的组成部分。

凸集要求任意两点之间整条线段留在集合中；图示和有限采样可以发现反例，却不能证明全称条件。连续、可微和二次可微支持不同层次的Taylor论证，不应在不可微折点直接调用光滑Newton的定理。

方向导数将梯度与移动方向联系起来：$Df(x)[p]=\nabla f(x)^Tp$。二阶Taylor还含曲率项，其高阶余项必须按所需光滑性控制。implicit function theorem解释约束消元、根支跟踪与局部参数化，但要求相应Jacobian非奇异等条件；不是全域坐标总存在的保证。

big-O与little-o记录误差的量级。$O(\|p\|^2)$指存在附近统一常数给界，$o(\|p\|^2)$则相对该尺度趋零；忽略二阶量与真正满足约束是不同结论。标量求根方法放在附录末，帮助理解线搜索里的插值与求参数过程。
