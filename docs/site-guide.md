# 找资料、读知识，少走一点弯路

初次来到这里，可以先看[课程目录](courses.html)的范围和先修要求，或从[自学路线](study-guide.html)开始。已经知道自己卡在哪一步时，用顶部搜索定位知识点，再按需打开[资料扩展](extensions.html)。

## 四个入口，怎样选择

| 现在要做什么 | 从哪里开始 | 下一步 |
| --- | --- | --- |
| 连续理解一门课 | [课程目录](courses.html) | 选课程，查看范围，沿章节顺序读 |
| 恢复知识之间的联系 | [学习路线](study-guide.html) | 先补必要基础，再读对应主线 |
| 为期末整理重点 | [期末复习](review-guide.html) | 对照教师范围，回读概念与适用条件 |
| 找原件或补充阅读 | [资料中心](resources.html) / [资料扩展](extensions.html) | 按课程筛选，查看用途、出处和获取状态 |

## 阅读正文与原图

左侧是所在课程或资料中心的导航，右侧是当前页面大纲；在手机上，它们分别位于“页面导航”和“本页大纲”。附加证明与算例可按需展开，搜索或深层链接会定位到相应内容。遥感页面可选择中文、English 或双语，讲义与教材配图可放大查看。

引用中的“文件页”从 PDF 第一页计数，“印刷页”指书页上印出的页码。它们可能不同，核对原文时以来源页的说明为准。

## 预览、下载与离线使用 {#downloads}

| 状态 | 实际提供什么 | 怎样获取 |
| --- | --- | --- |
| 站内下载 | 当前公开文件的原件或本站整理包 | 使用资源卡的下载按钮；具体包含内容见说明 |
| 外部下载 | 作者或维护项目提供的文件 | 跳转官方/维护入口；版本和可用性可能变化 |
| 仅本地存档 | 维护者保留的原件出处、页码和整理范围 | 原件仅维护者本地存档，本站没有全文下载；可阅读对应知识与来源说明 |
| 在线索引 | 资料与知识点的对应关系 | 阅读页面中的来源记录和返回正文链接 |

**PDF 预览空白或一直加载**：使用阅读页的“打开 PDF”备用入口，或下载后用本地阅读器打开。大文件需要更长时间；LeeDL 教材可从其[版本发布页](https://github.com/datawhalechina/leedl-tutorial/releases/tag/v1.2.4)获取。

**DOCX、PPTX 或 ZIP**：DOCX/PPTX 下载后使用兼容的文档软件；ZIP 需要先解压。InSAR 离线包包含本站整理的 Markdown、配图和来源记录，完整课堂 PDF 与教材不在包内。

**Notebook 与 Python**：网页用于看代码，下载后仍需本地 Python/PyTorch 环境。先读[实践环境与预算](cifar10-practice.html#p0)，再运行相应单元。保存代码或阅读网页不会自动训练模型。

下载文件的内容可在兼容阅读器中离线查看；代码执行仍需要相应环境与依赖，包内外部链接需要联网。当前网站没有整站离线安装或跨设备学习记录同步。

## 筛选结果可以分享吗

资料中心的课程、类型、获取方式与搜索词会反映在当前网址中。直接复制浏览器地址即可分享同一组条件，刷新页面会恢复它们。“重置筛选”会回到全部资源。课程正文也可以通过标题旁的链接分享具体知识点。

## 学习记录保存在哪里 {#records}

机器学习的阅读/掌握标记、继续阅读位置、主题和遥感语言偏好保存在当前浏览器的本地存储中，不需要登录。换浏览器、换设备、无痕模式或清除站点数据后，记录可能不会保留。

网站没有学习记录云同步功能。需要长期保存复习进度时，可以另外记录章节链接；不要把本地标记视为学习成果的自动评估。

## 发现错误或链接失效

文档页上方的“反馈本页问题”会打开预填当前网址的 GitHub Issue 表单，你确认内容后再提交。登录 GitHub 后可记录问题；网站不会替你自动发送。

请尽量附上页面、段落或锚点、问题现象和依据。完整说明见[反馈与修订](contribute.html#feedback)。网站的目标和制作者介绍见[制作者主页](about.html)。
