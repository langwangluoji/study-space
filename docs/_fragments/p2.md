## P2｜把图像变成 CHW 张量，再使用固定教学归一化 {#p2}

[↗ 第一讲：规范化与数据泄漏](lecture-1.html#a15)

<strong>目的：</strong>转换为 C × H × W 浮点张量：C 是颜色通道数，H 是高度，W 是宽度。原图常按 HWC 排列，输入网络前改为 CHW。本课程为保持 quick run 可复现，使用预先固定的对称教学归一化；它不从当前数据集估计均值或尺度，因此不会让验证、测试样本参与统计量拟合。若改成按数据计算均值和标准差，则这些统计量只能由训练部分得到。



<strong>通过：</strong>单样本形状 [3,32,32]、float32。

<strong>常见错：</strong>把 HWC 当 CHW，或让验证/测试数据参与统计量计算。
