# 两本教材怎样融合：顺序、符号与来源

讲义按 *Introduction to Modern Photogrammetry* 的章节与核心小节顺序学习。王佩军、徐亚明教材提供的中文解释、特殊点线面、两类相对定向、三类区域网与GPS/POS等内容，放入相应英文主题中连续讲解。两本书都作为内容来源，不把其中一本只当术语表。

## 先对概念，再对字母 {#symbols}

|概念|本讲采用的约定|读原书时需要核对|
|---|---|---|
|标定主距 principal distance|几何节沿王书用$f$；光学节以$c_p$区别光学焦距$f$|名字相近不表示有限距对焦时数值相同|
|相机与物空间旋转|王书式$R$为相机→辅助；辅助平行物方时$q=R^T(P-C)$|原著别处同名字母可能表示反向矩阵，先看输入输出|
|摄站高程与相对航高|高程写$Z_S$或明确的$H_s$，相对局部地面距离$H=Z_S-Z_g$|经验折光式的$H,h$另用同一海面参考，不能换成局部相对航高|
|摄影比例尺|比例值$f/H$，分母$m=H/f$|不能把“比例尺增大”读成分母增大|
|像坐标、像元与地面坐标|像面常用mm，地面常用m；像元间隔先换为与主距相同单位|扫描坐标、主点中心坐标与归一化坐标不混用|
|模型到地面的尺度|同长度单位时无量纲；模型采用任意单位时可带m/模型单位|不能无条件把尺度都称无量纲|
|残差与雅可比|$J$为预测值导数；$r=z-g$导数为$-J$，$v=g-z$导数为$+J$|误差方程的符号和右端必须配套|

## 负坐标像面不是物理感光片位置的断言 {#image-plane}

为保持王书已核公式，本讲用投影向量 $a=(x-x_0,y-y_0,-f)^T$，并写 $x-x_0=-fq_x/q_z$。这里的$z=-f$首先是**所选等效投影面坐标**，不能只因存在负号就称它位于相机后方的真实感光片。

<SourceFigure src="/photogrammetry/figures/equivalent-image-plane.svg" alt="同一空间直线的等效投影向量与物理感光面分开理解" source="原创坐标示意" page="坐标约定" :original="true" note="图示只说明同一直线可以用反向比例向量表达；具体感光面轴向和读片方向仍由相机及检校约定决定。" />

在本讲近垂直例中，地面$Z$向上，$R=I$，地面点在相机下方，故$q_z<0$。例如$P-C=(200,100,-1000)$ m、$f=100$ mm，投影为$(20,10)$ mm，选用$a=(20,10,-100)$ mm与物方方向同向。它是用来表达空间视线的等效构造；不表示光穿过镜头后还留在同一侧。

换成$-a$仍表示同一条无向空间直线，但正向可见射线的参数符号会改变。采用“向场景为正深度”的另一坐标系时，投影与视差差序也须一起转换，不能一边换轴，一边保留原来的差序。

沿用上面的同一组轴：左右相机沿$+X$分开$B>0$，地面在相机下方，令$D=-q_z>0$。主点中心坐标满足

$$x_L=fX/D,\qquad x_R=f(X-B)/D,\qquad p=x_L-x_R=fB/D.$$

这里$X$相对左摄站，两个相机均无旋转；$D$是向下距离，不是把整个坐标系改成向下为正。于是$D=fB/p$；物点越高，$D$越小，正视差越大。其他读片轴向或差序的教材可有不同符号，必须连同坐标轴整体转换。对本讲$a=(x-x_0,y-y_0,-f)^T$的近垂直可见点，$\lambda>0$表示向场景的射线；若将方向换成$-a$，同一物点的参数随之变负。
