# 大地测量课程维护方案

课程以绪论与椭球面数学性质两个主章组织。每章先有总览，再进入专题；一般理论用简单对象解释后，立即应用到椭球。关键证明用连续正文展开，不把每个定义拆成一组重复的模块或问答。

## 内容与来源

绪论包含四个专题，椭球章包含六个专题，唯一目录配置是 geodesy.config.json。原讲义图像位于 public/geodesy/figures，清单记录原文件、文件页、原页码、裁切区域和 SHA-256。正文使用 SourceFigure 组件显示出处并支持放大。

四份辅助材料按知识点引用。轨道课件只参考坐标变换。旧草稿入口保留为简短来源或拓展说明，不进入主章目录。当前不设置习题、自测或练习区。

## 编辑与核验

正文先说明几何问题，再引入符号与条件，随后逐步推导。公式与段落互相解释，只有重复代数展开可以折叠。基向量朝向、角度单位、参数范围和近似阶数必须写清。

运行 python scripts/verify_geodesy.py，使用 SymPy 1.14.0 与 mpmath 1.3.0 核验展示的恒等式和独立积分。随后运行 npm run build 与 node scripts/check-ui.cjs，检查公式、内部链接、旧锚点、搜索、交互、配图放大、手机与原课程兼容性。依赖声明为 requirements-geodesy.txt，CI 已接入。

## 后续维护

增加新内容时，先确认两主章内的概念依赖，再选取对应原页和图像。当前公式推导的边界应保留，不能把截断级数的迭代残差当作精确积分误差。未来习题与工程专题需另有明确任务，不随普通资料更新自动扩充。
