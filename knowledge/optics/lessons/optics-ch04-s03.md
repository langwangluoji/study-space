来源：PPT p.5至8；介质中的换算、细分波段应用与分子谱结构为教材/电动力学补充。

光线表示光能传播方向，在适用几何光学近似时沿能流方向；电动力学中能流密度为 $\mathbf S=\mathbf E\times\mathbf H$。光束是一组具有一定几何关系的光线。同心光束的光线交于一点或其反向延长线交于一点；像散光束通常没有唯一公共交点。

真空中

$$
c=\lambda_0\nu,\qquad \omega=2\pi\nu,\qquad k_0=2\pi/\lambda_0.
$$

可见光约为 $390\!\sim\!780\,\mathrm{nm}$，对应约 $7.7\times10^{14}\!\sim\!3.8\times10^{14}\,\mathrm{Hz}$。波长增加时频率降低；光经过静止界面时频率保持不变，介质中的波长和相速度满足 $\lambda=\lambda_0/n$、$v_p=\lambda\nu=c/n$。

电磁谱按频率递增的大致顺序是无线电 → 微波/太赫兹 → 红外 → 可见 → 紫外 → X 射线 → $\gamma$ 射线。边界依学科约定略有重叠；X 与 $\gamma$ 的名称还常按产生机制区分。通信、热成像、医疗 X 射线等应用都遵循同一关系 $E_\gamma=h\nu=hc/\lambda_0$：越短波的单光子能量越高。

连续谱在一段频率范围内连续分布；窄带谱的能量集中在较小频宽内。频宽关系到时间相干性，完整的相干描述还包括统计相位关系和空间相关范围。

线状谱、带状谱和连续谱描述谱的结构，窄带或宽带描述能量占据的频宽。低压原子气体的分立跃迁形成线状谱；分子的电子能级叠加振动、转动子结构，密集谱线在有限分辨率下呈带状谱；热固体等可有连续分布。

不同谱段常对应不同的物质响应和观测手段。谱段边界采用约定范围，微波、THz、红外以及紫外、X射线之间有重叠。

| 波段 | 便于复习的范围或特征 | 典型物理联系与应用 |
|---|---|---|
| 无线电/微波 | 微波约 $30\,\mathrm{cm}$ 至 $1\,\mathrm{mm}$ | 电子线路、雷达、通信；分子转动跃迁可落在微波 |
| 太赫兹 | 教材取约 $0.1\!\sim\!10\,\mathrm{THz}$，即 $3\,\mathrm{mm}\!\sim\!30\,\mu\mathrm m$ | 水吸收强，一些干燥非极性材料较易透过，用于成像与物性探测 |
| 红外 | 约 $780\,\mathrm{nm}$ 至 $1\,\mathrm{mm}$ | 热辐射、分子振动、红外遥感；人体 $T\sim310\,\mathrm K$ 的黑体近似谱峰约 $9.35\,\mu\mathrm m$ |
| 可见 | 教材取 $400\!\sim\!780\,\mathrm{nm}$，课件取 $390\!\sim\!780\,\mathrm{nm}$ | 人眼响应在边界附近逐渐减弱；辐射度学计能量，光度学按人眼响应加权 |
| 紫外/极紫外 | 波长短于可见紫光；教材将约 $120\!\sim\!5\,\mathrm{nm}$ 列为极紫外 | 化学、电子激发及电离；较短波长可改善衍射分辨率，空气在部分短波段强吸收 |
| X射线 | 兼有连续轫致谱与特征线谱 | 医学成像、衍射和吸收谱；X射线管中的连续谱来自轫致辐射，特征线谱来自内壳层跃迁 |
| $\gamma$射线 | 常与核跃迁等高能过程联系 | 核与高能探测；与X射线按能量划分存在重叠，还常按来源区分 |

波长、频率和单光子能量按 $E[\mathrm{eV}]\simeq1239.84/\lambda_0[\mathrm{nm}]$、$\nu=c/\lambda_0$ 换算。例如 $400\,\mathrm{nm}$ 对应 $7.49\times10^{14}\,\mathrm{Hz}$。选定一个谱段端点后，其余数值由这两个关系得到。

短例题：$\lambda_0=600\,\mathrm{nm}$ 的光，$\nu\simeq5.00\times10^{14}\,\mathrm{Hz}$，单光子能量约 $2.07\,\mathrm{eV}$。进入 $n=1.50$ 的静止介质后，频率仍为该值，波长变为 $400\,\mathrm{nm}$。看到“400 nm”时，应先确认指真空波长还是介质内波长。

自检：把这束光移入玻璃会使它从红色变成紫色吗？为什么带状谱仍可包含大量分立跃迁？

#### 自检答案：波长和谱形



颜色对应的频率保持不变，介质内波长缩短来自相速度改变。带谱常由密集的振动、转动子结构组成，有限仪器分辨率把相邻线合成谱带；“带状”说明观测谱形。
